## 两数相乘

下面是一个把用户给定的两个数相乘的 Java 程序：

### 示例 1：两整数相乘的程序

```java
import java.util.Scanner;

class Main {

  public static void main(String[] args) {

    Scanner input = new Scanner(System.in); // 创建一个 Scanner 对象

    System.out.print("Enter two numbers: "); // 从用户处获取输入
    int first = input.nextInt();
    int second = input.nextInt();

    System.out.println("Entered numbers are: " + first + " " + second);

    // 两数相乘
    int multiplication = first * second;
    System.out.println("Multiplication: " + first + " * " + second + " = " + multiplication);

    input.close();
  }
}
```

#### 输出

```plaintext
Enter two numbers: 10 2
Entered numbers are: 10 2
Multiplication: 10 * 2 = 20
```

就像[上一个程序](/programs/add-two-integers#example-program-to-add-two-integers)中做加法那样，

`first` 和 `second` 使用 `*` 运算符相乘，结果存入另一个变量 `multiplication` 中。

然后，`multiplication` 连同一些[字符串拼接](/docs/basic-input-output#example-print-concatenated-strings)通过 `println()` 函数打印到屏幕上。

<Callout>

不知道怎么从用户那里获取输入？看看[这些示例](/docs/basic-input-output#java-input)

### 示例 2：两个小数相乘的程序

_乘法也可以在正数和负数之间进行。_

```java
import java.util.Scanner;

class Main {

  public static void main(String[] args) {

    Scanner input = new Scanner(System.in); // 创建一个 Scanner 对象

    System.out.print("Enter two numbers: "); // 从用户处获取输入
    double first = input.nextDouble();
    double second = input.nextInt();

    System.out.println("Entered numbers are: " + first + " " + second);

    // 两数相乘
    double multiplication = first * second;
    System.out.println("Multiplication: " + first + " * " + second + " = " + multiplication);

    input.close();
  }
}
```

#### 输出

```plaintext
Enter two numbers: -13.0 2.3
Entered numbers are: -13.0 2.3
Multiplication: -13.0 * 2.3 = -29.9
```

变量 `multiplication` 的数据类型是 `double`，因为两个数据类型为 `double` 的数相乘，结果也是 `double`。

<Callout>

**注意：** 这里的输出 `multiplication` 是负数，因为这些运算遵循[标准数学规则](https://en.wikipedia.org/wiki/Multiplication#Properties)。

</Callout>
