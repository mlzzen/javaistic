## 1. 打印一个整数

下面是一个打印用户预先定义的数的 Java 程序：

### 示例：如何打印一个整数

#### 输入

```java
public class HelloWorld {

    public static void main(String[] args) {

        // 声明一个变量来存储该整数
        int number = 10;

        // println() 将下面这一行打印到输出屏幕
        System.out.println("The number is: " + number);
    }
}

```

#### 输出

```plaintext
The number is: 10
```

在本程序中，我们打印的是一个一开始就定义好的常量整数值。
这个整数通过关键字 `int` 存储在整型变量 `number` 中，并使用关键字 `println` 打印出来。

## 2. 打印一个整数（由用户输入）

下面是一个打印用户输入的数的 Java 程序：

### 示例：如何打印用户输入的一个整数

#### 输入

```java
import java.util.Scanner;

public class HelloWorld {

    public static void main(String[] args) {

        // 创建一个读取器实例，它从
        // 标准输入——键盘——读取输入
        Scanner reader = new Scanner(System.in);
        System.out.print("Enter a number: ");

        // nextInt() 从键盘读取下一个整数
        int number = reader.nextInt();

        // println() 将下面这一行打印到输出屏幕
        System.out.println("You entered: " + number);
    }
}

```

#### 输出

```plaintext
Enter a number: 10
You entered: 10
```

在本程序中，创建了 `Scanner` 类的一个对象 `reader`，用于从标准输入（也就是键盘）获取输入。

随后会打印 `Enter a number` 提示，让用户直观地知道下一步该做什么。

接着 `reader.nextInt()` 会从键盘读取所有输入的整数，直到遇到换行符 `\n (Enter)` 为止。这些输入的整数随后会保存到整型变量 `number` 中。

如果你输入任何不是整数的字符，编译器会抛出 `InputMismatchException`。

最后，`number` 会通过 `println()` 函数打印到标准输出 `(System.out)`，也就是计算机屏幕上。
