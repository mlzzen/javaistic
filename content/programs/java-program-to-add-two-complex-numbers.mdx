## 在 Java 中相加两个复数

在本程序中，我们有一个类 `ComplexNumber`。这个类里有两个实例变量 `real` 和 `img`，分别存放复数的实部和虚部。

我们声明了一个方法 sum()，通过把两个数的实部和虚部分别相加来[将这两个数相加](./add-two-integers)。

这个类的构造方法用于初始化复数。例如，当我们像这样创建该类的实例 `ComplexNumber temp = new ComplexNumber(0, 0);` 时，它实际上创建了复数 `0 + 0i`。

### 代码：

```java
public class ComplexNumber{
   //用于存放复数的实部和虚部
   double real, img;

   //构造方法，用于初始化复数
   ComplexNumber(double r, double i){
	this.real = r;
	this.img = i;
   }

   public static ComplexNumber sum(ComplexNumber c1, ComplexNumber c2)
   {
	//创建一个临时复数，用于存放两个数之和
        ComplexNumber temp = new ComplexNumber(0, 0);

        temp.real = c1.real + c2.real;
        temp.img = c1.img + c2.img;

        //返回结果复数
        return temp;
    }
    public static void main(String args[]) {
	ComplexNumber c1 = new ComplexNumber(5.5, 4);
	ComplexNumber c2 = new ComplexNumber(1.2, 3.5);
        ComplexNumber temp = sum(c1, c2);
        System.out.printf("Sum is: "+ temp.real+" + "+ temp.img +"i");
    }
}
```

### 输出：

```plaintext
Sum is: 6.7 + 7.5i
```
