## 1. 两数相加

下面是一个把用户预先定义的两个数相加的 Java 程序：

### 示例：两数相加的程序

#### 输入

```java
class Main {

  public static void main(String[] args) {

    System.out.println("Enter two numbers");
    int first = 10;
    int second = 20;

    System.out.println(first + " " + second);

    // 两数相加
    int sum = first + second;
    System.out.println("The sum is: " + sum);
  }
}
```

#### 输出

```plaintext
Enter two numbers
10 20
The sum is: 30
```

在本程序中，两个整数 `10` 和 `20` 分别存储在整型变量 `first` 和 `second` 中。

然后，`first` 和 `second` 使用 `+` 运算符相加，结果存入另一个变量 `sum` 中。

最后，`sum` 通过 `println()` 函数打印到屏幕上。
