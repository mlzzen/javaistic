交换两个数是 Java 中常见的入门练习。下面介绍三种简单的实现方式：

- 使用临时变量（最安全、最易读）
- 使用算术运算（注意：数值非常大时可能溢出）
- 使用按位异或（无需临时变量；适用于整数）

开始之前，你可以先复习：

- [Java 变量与字面量](/docs/variables-and-literals)
- [Java 运算符](/docs/operators)
- [Java 基础输入与输出](/docs/basic-input-output)

## 1) 使用临时变量交换

这是最直接、也是推荐的做法。

### 示例

```java
class Main {
  public static void main(String[] args) {
    int a = 10;
    int b = 20;

    System.out.println("Before swap: a = " + a + ", b = " + b);

    int temp = a; // 把 a 存起来
    a = b;        // 把 b 放入 a
    b = temp;     // 把原来的 a 放入 b

    System.out.println("After swap:  a = " + a + ", b = " + b);
  }
}
```

#### 输出

```plaintext
Before swap: a = 10, b = 20
After swap:  a = 20, b = 10
```

## 2) 不用临时变量交换（算术运算）

使用加法和减法。注意：当数值接近整数上限时可能溢出。

### 示例

```java
class Main {
  public static void main(String[] args) {
    int a = 15;
    int b = 27;

    System.out.println("Before swap: a = " + a + ", b = " + b);

    a = a + b; // a 变成两数之和
    b = a - b; // b 变成原来的 a
    a = a - b; // a 变成原来的 b

    System.out.println("After swap:  a = " + a + ", b = " + b);
  }
}
```

#### 输出

```plaintext
Before swap: a = 15, b = 27
After swap:  a = 27, b = 15
```

## 3) 使用异或交换（不用临时变量）

适用于整数，且不需要额外的内存，但对初学者来说可读性较差。

### 示例

```java
class Main {
  public static void main(String[] args) {
    int a = 5;
    int b = 9;

    System.out.println("Before swap: a = " + a + ", b = " + b);

    a = a ^ b; // 第 1 步
    b = a ^ b; // 第 2 步：此时 b 是原来的 a
    a = a ^ b; // 第 3 步：此时 a 是原来的 b

    System.out.println("After swap:  a = " + a + ", b = " + b);
  }
}
```

#### 输出

```plaintext
Before swap: a = 5, b = 9
After swap:  a = 9, b = 5
```

---

### 应该用哪种方式？

- 为了清晰和安全，优先使用临时变量法。
- 算术法是个不错的小技巧，但当数值可能溢出时应避免使用。
- 异或是一种有趣的技巧；只有当它确实带来价值、且不牺牲可读性时才使用。
