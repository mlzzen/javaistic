## 判断闰年

下面是一个判断给定年份是否为闰年的 Java 程序：

```java
import java.util.Scanner;

class checkLeapYear{
  public static void main(String[] args){
    int year;
    boolean isLeapYear;
    System.out.print("Enter the year to check: ");
    // Scanner 类的实例
    Scanner input = new Scanner(System.in);
    // 把用户输入存入 year 变量
    year = input.nextInt();
    // 检查该年份是否为闰年
    isLeapYear = year % 4 == 0;

    if(isLeapYear){
        System.out.println(year + " is leap year");
    }else{
        System.out.println(year + " isn't leap year");
    }
    input.close();
  }
}
```

#### 输出 1

```plaintext
Enter the year to check: 2003
2003 isn't leap year
```

#### 输出 2

```plaintext
Enter the year to check: 2004
2004 is leap year
```

要判断某个 `year` 是否 `leap`（闰年），我们只需检查它是否 `divisible by 4`：如果除后没有余数，就是闰年，否则不是闰年。
