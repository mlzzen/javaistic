## 引言

反转数字是一个基础编程概念：从右到左逐位取出数字，再按相反顺序重新组合。例如，反转 1234 会得到 4321。

这个程序演示了在 Java 中反转数字的多种方法，从基本的迭代方法到更高级的技巧。

## 方法 1：使用 while 循环（最常用）

这是最直观的方法，通过提取各位数字和数学运算实现。

```java
import java.util.Scanner;

public class ReverseNumber {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number to reverse: ");
        int number = scanner.nextInt();

        int originalNumber = number;
        int reversedNumber = 0;

        // 处理负数
        boolean isNegative = number < 0;
        number = Math.abs(number);

        while (number != 0) {
            int digit = number % 10;           // 取出最后一位
            reversedNumber = reversedNumber * 10 + digit;  // 构造反转后的数字
            number = number / 10;              // 去掉最后一位
        }

        // 如果原数是负数，则补上符号
        if (isNegative) {
            reversedNumber = -reversedNumber;
        }

        System.out.println("Original number: " + originalNumber);
        System.out.println("Reversed number: " + reversedNumber);

        scanner.close();
    }
}
```

**输出：**

```
Enter a number to reverse: 1234
Original number: 1234
Reversed number: 4321
```

## 方法 2：使用 for 循环

同样的逻辑也可以用 for 循环实现，代码更紧凑，但需要事先知道数字的位数。

```java
import java.util.Scanner;

public class ReverseNumberForLoop {

    // 统计数字位数的方法
    public static int countDigits(int number) {
        if (number == 0) return 1;
        int count = 0;
        number = Math.abs(number);
        while (number > 0) {
            count++;
            number /= 10;
        }
        return count;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number to reverse: ");
        int number = scanner.nextInt();

        int originalNumber = number;
        int reversedNumber = 0;
        boolean isNegative = number < 0;
        number = Math.abs(number);

        int digitCount = countDigits(number);

        for (int i = 0; i < digitCount; i++) {
            int digit = number % 10;
            reversedNumber = reversedNumber * 10 + digit;
            number = number / 10;
        }

        if (isNegative) {
            reversedNumber = -reversedNumber;
        }

        System.out.println("Original number: " + originalNumber);
        System.out.println("Reversed number: " + reversedNumber);

        scanner.close();
    }
}
```

## 方法 3：使用字符串操作

这种方法把数字转换成字符串，并使用内置的字符串方法。

```java
import java.util.Scanner;

public class ReverseNumberString {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number to reverse: ");
        int number = scanner.nextInt();

        // 转换为字符串并处理负号
        String numberStr = String.valueOf(Math.abs(number));

        // 反转字符串
        String reversedStr = new StringBuilder(numberStr).reverse().toString();

        // 再转换回整数
        int reversedNumber = Integer.parseInt(reversedStr);

        // 如果原数是负数，则补上负号
        if (number < 0) {
            reversedNumber = -reversedNumber;
        }

        System.out.println("Original number: " + number);
        System.out.println("Reversed number: " + reversedNumber);

        scanner.close();
    }
}
```

## 方法 4：使用递归

一种体现函数式编程思想的递归方法。

```java
import java.util.Scanner;

public class ReverseNumberRecursive {

    // 递归反转数字的方法
    public static int reverseNumber(int number, int reversedNumber) {
        if (number == 0) {
            return reversedNumber;
        }

        int digit = number % 10;
        reversedNumber = reversedNumber * 10 + digit;

        return reverseNumber(number / 10, reversedNumber);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number to reverse: ");
        int number = scanner.nextInt();

        boolean isNegative = number < 0;
        int absoluteNumber = Math.abs(number);

        int reversedNumber = reverseNumber(absoluteNumber, 0);

        if (isNegative) {
            reversedNumber = -reversedNumber;
        }

        System.out.println("Original number: " + number);
        System.out.println("Reversed number: " + reversedNumber);

        scanner.close();
    }
}
```

## 方法 5：带回文判断的完整程序

这个增强版本还会判断该数是否为回文数。

```java
import java.util.Scanner;

public class CompleteReverseNumber {

    public static int reverseNumber(int number) {
        int reversedNumber = 0;
        number = Math.abs(number);

        while (number != 0) {
            int digit = number % 10;
            reversedNumber = reversedNumber * 10 + digit;
            number = number / 10;
        }

        return reversedNumber;
    }

    public static boolean isPalindrome(int number) {
        int absNumber = Math.abs(number);
        return absNumber == reverseNumber(absNumber);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number to reverse: ");
        int number = scanner.nextInt();

        int reversedNumber = reverseNumber(number);

        // 如果原数是负数，则补上负号
        if (number < 0) {
            reversedNumber = -reversedNumber;
        }

        System.out.println("Original number: " + number);
        System.out.println("Reversed number: " + reversedNumber);

        // 判断是否为回文数
        if (isPalindrome(number)) {
            System.out.println(Math.abs(number) + " is a palindrome!");
        } else {
            System.out.println(Math.abs(number) + " is not a palindrome.");
        }

        scanner.close();
    }
}
```

**示例输出：**

```
Enter a number to reverse: 12321
Original number: 12321
Reversed number: 12321
12321 is a palindrome!
```

## 核心概念讲解

### 1. **提取各位数字**

- `number % 10` 取出最后一位数字
- `number / 10` 去掉最后一位数字

### 2. **构造反转后的数字**

- `reversedNumber * 10 + digit` 把取出的数字加到左侧

### 3. **处理负数**

- 单独保存符号，最后再补上
- 反转过程中只处理绝对值

### 4. **边界情况**

- 一位数（0-9）
- 负数
- 末尾带零的数（例如 1200 会变成 21）

## 时间与空间复杂度

- **时间复杂度**：O(log n)，其中 n 是输入的数值（即数字的位数）
- **空间复杂度**：迭代方法为 O(1)，递归方法为 O(log n)

## 常见应用

1. **回文检测**：判断一个数正着读和倒着读是否相同
2. **数学运算**：各类数论问题
