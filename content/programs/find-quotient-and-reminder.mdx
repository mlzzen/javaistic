## 计算商和余数

一个求商和余数的 Java 程序如下：

```java
import java.util.Scanner;
public class quotient_reminder {
    public static void main(String[] args){
        int dividend, divisor;
        Scanner input = new Scanner(System.in);
        System.out.print("Enter the dividend: ");
        dividend = input.nextInt();
        System.out.print("Enter the divisor: ");
        divisor = input.nextInt();
        int quotient = dividend / divisor;
        int reminder = dividend % divisor;

        System.out.println("Quotient: " + quotient + "\nReminder: " + reminder);
        input.close();
    }
}
```

### 输出 1：

```plaintext
Enter the dividend: 11
Enter the divisor: 15
Quotient: 0
Reminder: 11
```

### 输出 2：

```plaintext
Enter the dividend: 100
Enter the divisor: 8
Quotient: 12
Reminder: 4
```

要计算商或余数，首先需要两个数作为前提，除法运算将在这两个数之间进行，从而求出商或余数。

这里，我们根据提示从用户处获取两个输入，并把这些值存入变量 `dividend` 和 `divisor`。要计算商，我们需要用一个数（被除数）除以另一个数（除数），除法运算后得到的结果就是商。
因此，这里我们用 `/` 运算符执行除法运算，并把结果存入 `quotient` 变量。

那余数呢？很多时候除法并不是整除的。因此，为了计算余数，我们用取模运算符来求，并把它存入 `reminder` 变量。
得到商和余数后，我们把它们打印出来。
