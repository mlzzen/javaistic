## 检查输入的字符

一个判断输入字符是元音还是辅音的 Java 程序如下：

### 代码：

```java
import java.util.Scanner;

public class VowelOrConsonant {
    public static void main(String[] args) {
               Scanner scanner = new Scanner(System.in);

        // 从用户处输入字符
        System.out.print("Enter a single alphabet character: ");
        char alphabet = scanner.next().charAt(0);
        char ch = String.valueOf(alphabet).toLowerCase().charAt(0);
        // 检查输入是否为字母
        if ((ch >= 'a' && ch <= 'z')) {
            // 检查是否为元音
            if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
                System.out.println(alphabet + " is a vowel.");
            } else {
                System.out.println(alphabet + " is a consonant.");
            }
        } else {
            System.out.println("Invalid input. Please enter an alphabet letter.");
        }
        scanner.close();
    }
}

```

### 输出：

```plaintext
Enter a single alphabet character: E
E is a vowel.

Enter a single alphabet character: f
f is a consonant.

```

这个 Java 程序：

接收单个字符作为输入。

将其转换为小写。

检查它是否为字母。

如果是元音（a、e、i、o、u），就打印 “vowel”。

否则，打印 “consonant”。

如果不是字母，就打印 “Invalid input”。

简单而有效，适用于基本的字符分类。
