回文数正着读和倒着读都一样（例如 121、1331、7）。本文中，我们将实现两种判断一个数是否为回文数的方法：

- 反转该数并与原数比较
- 转换为字符串并与它的反转结果比较

## 1）数学方法（反转数字）

这种方法通过提取各位数字，用数学方式反转该数。



### 示例

```java
class Main {
  public static void main(String[] args) {
    int num = 121; // change value to test

    if (isPalindrome(num)) {
      System.out.println(num + " is a palindrome number.");
    } else {
      System.out.println(num + " is not a palindrome number.");
    }
  }



  static boolean isPalindrome(int num) {
    int original = num;
    int reversed = 0;

    // 处理负数
    if (num < 0) return false;

    // 反转数字
    while (num > 0) {
      int digit = num % 10;
      reversed = reversed * 10 + digit;
      num /= 10;
    }

    return original == reversed;
  }
}

```

#### 输出（num = 121）
```plaintext
121 is a palindrome number.
```

## 2）字符串比较方法

把数字转换成字符串，再与它的反转结果比较。



### 示例

```java
class Main {
  public static void main(String[] args) {
    int num = 1234; // change value to test

    if (isPalindromeString(num)) {
      System.out.println(num + " is a palindrome number.");
    } else {
      System.out.println(num + " is not a palindrome number.");
    }
  }



  static boolean isPalindromeString(int num) {
    // 处理负数
    if (num < 0) return false;

    String original = String.valueOf(num);
    String reversed = new StringBuilder(original).reverse().toString();

    return original.equals(reversed);
  }
}

```

#### 输出（num = 1234）
```plaintext
1234 is not a palindrome number.
```

## 3）交互式程序

一个接收用户输入并测试多个数字的完整程序。



### 示例

```java
import java.util.Scanner;

class Main {
  public static void main(String[] args) {
    Scanner scanner = new Scanner(System.in);

    System.out.print("Enter a number to check: ");
    int num = scanner.nextInt();

    System.out.println("\nChecking " + num + "...");

    // 方法 1：数学方法
    boolean result1 = isPalindromeMath(num);
    System.out.println("Mathematical method: " + (result1 ? "Palindrome" : "Not palindrome"));

    // 方法 2：字符串方法
    boolean result2 = isPalindromeString(num);
    System.out.println("String method: " + (result2 ? "Palindrome" : "Not palindrome"));

    scanner.close();
  }



  static boolean isPalindromeMath(int num) {
    if (num < 0) return false;
    int original = num, reversed = 0;
    while (num > 0) {
      reversed = reversed * 10 + num % 10;
      num /= 10;
    }
    return original == reversed;
  }

  static boolean isPalindromeString(int num) {
    if (num < 0) return false;
    String str = String.valueOf(num);
    return str.equals(new StringBuilder(str).reverse().toString());
  }
}

```

#### 示例输出

```plaintext
Enter a number to check: 12321

Checking 12321...
Mathematical method: Palindrome
String method: Palindrome
```

### 说明与提示

- **性能**：数学方法通常更快，因为它避免了字符串操作
- **边界情况**：负数通常不被视为回文数
- **常见回文数**：0、1、11、22、101、121、131、1001、1221 等
- **内存**：数学方法使用 O(1) 空间，字符串方法使用 O(log n) 空间
