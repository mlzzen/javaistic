## Java 中的“this”关键字是什么？

在 Java 中，`this` 关键字用在类内部，指向该类的当前实例（对象）。它常用于方法或构造方法中，用来引用当前对象的属性，或者在同一个类中调用其他构造方法。

### 示例

```java
class Main {
    int instVar;

    Main(int instVar) {
        this.instVar = instVar;
        System.out.println("this reference = " + this);
    }

    public static void main(String[] args) {
        Main obj = new Main(8);
        System.out.println("object reference = " + obj);
    }
}
```

### 输出

```bash
this reference = Main@23fc625e
object reference = Main@23fc625e
```

在这个示例中，`this` 指向 Main 的 `obj` 实例。`this` 和 `obj` 共享同一个内存引用，说明它代表的就是当前对象。

## this 关键字的常见用法

### 1. 解决变量名冲突

当实例变量和参数同名时，使用 `this` 可以帮助消除歧义：

```java
class MyClass {
    int age;

    MyClass(int age) {
        this.age = age; // 用 `this` 区分实例变量与参数
    }
}
```

不使用 `this` 时：

```java
class Main {
    int age;
    Main(int age) {
        age = age; // 没有 `this`，所以不会给实例变量赋值
    }

    public static void main(String[] args) {
        Main obj = new Main(8);
        System.out.println("obj.age = " + obj.age); // 输出：obj.age = 0
    }
}
```

### 2. 在 getter 和 setter 中使用 this

`this` 常用于 setter 方法中，用来区分实例变量和参数：

```java
class Main {
    String name;

    void setName(String name) {
        this.name = name;
    }

    String getName() {
        return this.name;
    }

    public static void main(String[] args) {
        Main obj = new Main();
        obj.setName("Toshiba");
        System.out.println("obj.name: " + obj.getName());
    }
}
```

### 输出

```bash
obj.name: Toshiba
```

### 3. 用 this() 实现构造方法重载

在构造方法重载中，可以用 `this()` 调用同一个类中的另一个构造方法，从而减少代码重复：

```java
class Complex {
    private int a, b;

    // 有两个参数的构造方法
    Complex(int i, int j) {
        this.a = i;
        this.b = j;
    }

    // 单参数构造方法调用双参数构造方法
    Complex(int i) {
        this(i, i);
    }

    // 无参构造方法调用单参数构造方法
    Complex() {
        this(0);
    }

    @Override
    public String toString() {
        return this.a + " + " + this.b + "i";
    }

    public static void main(String[] args) {
        Complex c1 = new Complex(2, 3);
        Complex c2 = new Complex(3);
        Complex c3 = new Complex();

        System.out.println(c1); // 输出：2 + 3i
        System.out.println(c2); // 输出：3 + 3i
        System.out.println(c3); // 输出：0 + 0i
    }
}
```

在这里，`this()` 有助于管理多个构造方法，提高可读性并减少代码重复。不过要谨慎使用，因为过度使用会拖慢程序的运行速度。

### 4. 把 this 作为参数传递

你可以用 `this` 把当前对象作为参数传给其他方法：

```java
class ThisExample {
    int x;
    int y;

    ThisExample(int x, int y) {
        this.x = x;
        this.y = y;

        System.out.println("Before passing this:");
        System.out.println("x = " + this.x + ", y = " + this.y);

        add(this);

        System.out.println("After passing this:");
        System.out.println("x = " + this.x + ", y = " + this.y);
    }

    void add(ThisExample obj) {
        obj.x += 2;
        obj.y += 2;
    }

    public static void main(String[] args) {
        ThisExample obj = new ThisExample(1, -2);
    }
}
```

### 输出

```bash
Before passing this:
x = 1, y = -2
After passing this:
x = 3, y = 0
```

在这个示例中，`this` 让 `add()` 方法能够直接修改当前实例的变量。

## 要点

- **变量消歧：**实例变量和参数同名时，`this` 可以解决冲突。
- **getter 和 setter：**`this` 常用于 setter 中区分实例变量。
- **构造方法重载：**`this()` 可以调用同一个类中的其他构造方法，有助于减少代码冗余。
- **传递当前对象：**`this` 让你可以把当前对象作为方法参数传入，从而修改当前实例。
