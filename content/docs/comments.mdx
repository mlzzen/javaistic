在计算机编程中，注释是程序中会被 Java 编译器完全忽略的一部分。它们主要用于帮助程序员理解代码。例如：

```java
// 声明并初始化两个变量
int a = 1;
int b = 3;

// 打印输出
System.out.println("This is output");
```

这里，我们使用了以下注释：

- 声明并初始化两个变量
- 打印输出

## Java 中的注释类型

在 Java 中，有两种类型的注释：

- 单行注释
- 多行注释

### 单行注释

单行注释在同一行开始并在同一行结束。要编写单行注释，我们可以使用 `//` 符号。例如：

```java
// "Hello, World!" 程序示例

class Main {
    public static void main(String[] args) {
    {
        // 输出 "Hello, World!"
        System.out.println("Hello, World!");
    }
}
```

输出：

```plaintext
Hello, World!
```

这里，我们使用了两个单行注释：

- `"Hello, World!" program example`
- `prints "Hello World!"`

Java 编译器会忽略从 `//` 到行尾的所有内容。因此，它也被称为**行尾注释**（End of Line comment）。

### 多行注释

当我们需要跨多行写注释时，就可以使用多行注释。要编写多行注释，我们可以使用 `/*....*/` 符号。例如：

```java
/* 这是一个多行注释的示例。
 * 该程序将 "Hello, World!" 输出到标准输出。
 */

class HelloWorld {
    public static void main(String[] args) {
    {
        System.out.println("Hello, World!");
    }
}
```

输出：

```plaintext
Hello, World!
```

这里，我们使用了多行注释：

```java
/* 这是一个多行注释的示例。
* 该程序将 "Hello, World!" 输出到标准输出。
*/
```

这种注释也被称为**传统注释**（Traditional Comment）。在这种注释中，Java 编译器会忽略从 `/*` 到 `*/` 的所有内容。

## 正确使用注释

有一点你应该始终记住：注释不应当成为用英文解释写得糟糕的代码的替代品。你应当始终编写结构良好、自解释的代码。然后，再使用注释。

有人认为代码应当自我描述，注释应当尽量少用。不过，在我看来，使用注释并没有什么错。我们可以用注释来解释复杂的算法、正则表达式，或者说明在多种技术方案中为什么选择其中一种来解决问题。
