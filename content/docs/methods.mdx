## Java 中的方法是什么？

在 Java 中，方法是一组语句的集合，用于执行特定任务，并且可以选择向调用者返回结果。Java 方法也可以只执行任务而不返回任何值。方法通过省去重复输入代码的需要，实现了代码复用。重要的是，在 Java 中每个方法都必须属于某个类。

## Java 中方法的类型

- `用户定义方法`：程序员根据具体需求自行创建的方法。
- `标准库方法`：Java 提供的内置方法，可以直接使用。

## 声明 Java 方法

方法声明的基本语法是：

```java
returnType methodName() {
  // 方法体
}
```

1. **returnType：** 指定方法返回值的类型。如果方法不返回值，返回类型就是 void。
2. **methodName：** 用于调用该方法的标识符。
3. **方法体：** `{ }` 内的代码，定义了要执行的任务。

### 示例 1：

```java
int addNumbers() {
  // 代码
}
```

在这个示例中，`addNumbers()` 是方法名，它的返回类型是 `int`。

### 更详细的声明：

```java
modifier static returnType methodName(parameter1, parameter2, ...) {
  // 方法体
}
```

1. **modifier：** 定义访问类型（例如 public、private）。
2. **static：** 如果加上它，方法无需创建对象就能被调用。
3. **parameter1, parameter2, ...parameterN：** 传给方法的值。

### 示例 2：

Math 类中的 `sqrt()` 方法是静态的，因此可以用 `Math.sqrt()` 访问，而不需要创建 Math 的实例。

## 调用 Java 方法

要使用一个方法，就用方法名加上括号来调用它。

### Java 方法调用示例

```java
class Main {
  public int addNumbers(int a, int b) {
    return a + b;
  }

  public static void main(String[] args) {
    int num1 = 25, num2 = 15;
    Main obj = new Main(); // 创建 Main 类的对象
    int result = obj.addNumbers(num1, num2);
    System.out.println("Sum is: " + result);
  }
}
```

### 输出

```bash
Sum is: 40
```

这里，`addNumbers()` 方法接收两个参数并返回它们的和。由于它不是静态的，所以需要一个对象才能调用。

## 方法的返回类型

方法可以返回值，也可以不返回值。返回语句用于返回一个值。

### 示例 1：方法返回整数值

```java
public static int square(int num) {
  return num * num;
}
```

### 示例 2：方法不返回任何值

```java
// 函数不返回任何值，因此使用 void 关键字
public void printSquare(int num) {
  System.out.println(num * num);
}
```

## 方法参数

方法可以接收参数，参数就是传给方法的值。

### 示例

- **带参数：** `int addNumbers(int a, int b)`
- **不带参数：** `int addNumbers()`

调用带参数的方法时，你必须为每个参数提供值。

### 方法参数示例

```java
class Main {
  public void display1() {
    System.out.println("Method without parameter");
  }

  public void display2(int a) {
    System.out.println("Method with a single parameter: " + a);
  }

  public static void main(String[] args) {
    Main obj = new Main();
    obj.display1();          // 没有参数
    obj.display2(24);        // 单个参数
  }
}
```

### 输出

```bash
Method without parameter
Method with a single parameter: 24
```

## 标准库方法

Java 包含 Java 类库（JCL）中提供的内置方法，它们随 [JVM 与 JRE](/docs/jvm-jre-jdk)一起提供。

### 示例

```java
public class Main {
  public static void main(String[] args) {
    System.out.println("Square root of 4 is: " + Math.sqrt(4));
  }
}
```

### 输出

```bash
Square root of 4 is: 2.0
```

## 使用方法的好处

### 1. 代码复用

定义一次，多次使用。

```java
private static int getSquare(int x) {
 return x * x;
}
public static void main(String[] args) {
 for (int i = 1; i <= 5; i++) {
   System.out.println("Square of " + i + " is: " + getSquare(i));
 }
}
```

### 输出：

```bash
Square of 1 is: 1
Square of 2 is: 4
Square of 3 is: 9
Square of 4 is: 16
Square of 5 is: 25
```

### 2. 更好的可读性

把代码分组到方法中，可以让代码更易读、更易调试。
