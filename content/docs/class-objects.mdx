Java 是一门面向对象的编程语言。面向对象方法的核心思想，就是把复杂的问题拆解成更小的对象。

对象是任何拥有状态和行为的实体。例如，一辆自行车就是一个对象。它有：

- **状态**：静止、一挡等
- **行为**：刹车、加速等

在学习对象之前，我们先来了解 Java 中的类。

## Java 类

类是对象的蓝图。在创建对象之前，我们需要先定义类。

我们可以把类想象成房子的设计图（原型）。它包含关于楼层、门、窗户等的全部细节。我们根据这些描述来建造房子。房子就是对象。

既然同一份描述可以建造出许多房子，我们也可以从一个类创建出许多对象。

### 在 Java 中创建类

我们可以使用 `class` 关键字在 Java 中创建类。例如：

```java
class ClassName {
  // 字段
  // 方法
}
```

这里的 `fields` [（变量）](/docs/variables-literals)和[方法](/docs/methods)分别表示对象的**状态**和**行为**。

- 字段用于存储数据
- 方法用于执行某些操作

对于我们的 `bicycle` 对象，可以这样创建类：

```java
class Bicycle {

  // 状态或字段
  private int gear = 5;

  // 行为或方法
  public void braking() {
    System.out.println("Working of Braking");
  }
}
```

在上面的示例中，我们创建了一个名为 `Bicycle` 的类。它包含一个名为 `gear` 的字段和一个名为 `braking()` 的方法。

这里，`Bicycle` 是一个原型。现在，我们可以用这个原型创建任意数量的自行车。而且，所有自行车都会共享这个原型的字段和方法。

<Callout>

**注意：** 我们使用了 private 和 public 这两个关键字。它们被称为访问修饰符。想了解更多，请访问 Java 访问修饰符。

</Callout>

## Java 对象

对象被称为类的实例。例如，假设 Bicycle 是一个类，那么 MountainBicycle、SportsBicycle、TouringBicycle 等都可以看作这个类的对象。

在 Java 中创建对象
下面是我们创建类的对象的方法。

```java
className object = new className();

// 对于 Bicycle 类
Bicycle sportsBicycle = new Bicycle();

Bicycle touringBicycle = new Bicycle();
```

我们使用 `new` 关键字配合类的构造方法来创建对象。构造方法与方法类似，名称与类名相同。例如，`Bicycle()` 就是 `Bicycle` 类的构造方法。想了解更多，请访问 [Java 构造方法](/docs/constructors)。

这里，`sportsBicycle` 和 `touringBicycle` 是对象的名称。我们可以用它们来访问类的字段和方法。

如你所见，我们创建了这个类的两个对象。在 Java 中，我们可以为一个类创建多个对象。

<Callout>

**注意：** 类的字段和方法也被称为类的成员。

</Callout>

## 访问类的成员

我们可以用对象的名称配合 `.` 运算符来访问类的成员。例如：

```java
class Bicycle {

  // 类的字段
  int gear = 5;

  // 类的方法
  void braking() {
    ...
  }
}

// 创建对象
Bicycle sportsBicycle = new Bicycle();

// 访问字段和方法
sportsBicycle.gear;
sportsBicycle.braking();
```

在上面的示例中，我们创建了一个名为 `Bicycle` 的类。它包含一个名为 `gear` 的字段和一个名为 `braking()` 的方法。注意这条语句：

```java
Bicycle sportsBicycle = new Bicycle();
```

这里，我们创建了一个名为 sportsBicycle 的 Bicycle 对象。之后我们用这个对象访问类的字段和方法。

- `sportsBicycle.gear` - 访问字段 gear
- `sportsBicycle.braking()` - 访问方法 `braking()`

我们已经多次提到**方法**这个词。你将在下一章详细了解 [Java 方法](/docs/methods)。

现在我们理解了什么是类和对象，来看一个完整的可运行示例。

### 示例：Java 类与对象

```java
class Lamp {

  // 存储灯光的值
  // 灯亮时为 true
  // 灯灭时为 false
  boolean isOn;

  // 打开灯的方法
  void turnOn() {
    isOn = true;
    System.out.println("Light on? " + isOn);

  }

  // 关闭灯的方法
  void turnOff() {
    isOn = false;
    System.out.println("Light on? " + isOn);
  }
}

public class Main {
  public static void main(String[] args) {

    // 创建对象 led 和 halogen
    Lamp led = new Lamp();
    Lamp halogen = new Lamp();

    // 通过调用 turnOn() 方法
    // 打开灯
    led.turnOn();

    // 通过调用 turnOff() 方法
    // 关闭灯
    halogen.turnOff();
  }
}
```

#### 输出：

```plaintext
Light on? true
Light on? false
```

在上面的程序中，我们创建了一个名为 `Lamp` 的类。它包含一个变量 `isOn` 和两个方法 `turnOn()` 与 `turnOff()`。

在 `Main` 类中，我们创建了 `Lamp` 类的两个对象：`led` 和 `halogen`。然后我们用这些对象调用了类的方法。

- `led.turnOn()` - 它把 isOn 变量设为 true 并打印输出。
- `halogen.turnOff()` - 它把 isOn 变量设为 false 并打印输出。

在类内部定义的变量 `isOn` 也被称为实例变量。这是因为当我们创建类的对象时，这个对象被称为类的实例。而且，每个实例都会拥有自己的一份变量副本。

也就是说，`led` 和 `halogen` 对象会各自拥有自己的 `isOn` 变量副本。

### 示例：在同一个类内部创建对象

注意，在上一个示例中，我们是在另一个类中创建对象，并从那个类访问成员。

不过，我们也可以在同一个类内部创建对象。

```java
class Lamp {

  // 存储灯光的值
  // 灯亮时为 true
  // 灯灭时为 false
  boolean isOn;

  // 打开灯的方法
  void turnOn() {
    isOn = true;
    System.out.println("Light on? " + isOn);

  }

  public static void main(String[] args) {

    // 创建 Lamp 的对象
    Lamp led = new Lamp();

    // 使用对象访问方法
    led.turnOn();
  }
}
```

#### 输出

```plaintext
Light on? true
```

这里，我们是在同一个类的 `main()` 方法内部创建对象。
