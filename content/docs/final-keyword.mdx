---
title: Java final 关键字
description: 在本教程中，我们将学习如何使用 Java 的 `final` 关键字。
---

在 Java 中，`final` 关键字用于定义常量，可以用于变量、方法和类。把某个实体声明为 `final` 就能确保它只被赋值一次，这意味着：

- `final` 变量不能被重新赋值。
- `final` 方法不能被重写。
- `final` 类不能被继承（不能有子类）。

## 1. Java 中的 final 变量

`final` 变量一旦被赋值，它的值就不能再改变。例如：

```java
class Main {
  public static void main(String[] args) {

    // 创建一个 final 变量
    final int AGE = 32;

    // 尝试修改 final 变量
    AGE = 45;
    System.out.println("Age: " + AGE);
  }
}
```

在这个示例中，变量 `AGE` 被标记为 `final`，意味着它在首次赋值后值不能再改变。尝试重新赋值会导致编译错误：

```plaintext
cannot assign a value to final variable AGE
    AGE = 45;
    ^
```

<Callout title="注意">
  Java 中的 `final` 关键字常用于定义常量，常量通常用大写字母命名。
</Callout>

## 2. Java 中的 final 方法

`final` 方法不能被子类重写。例如：

```java
class FinalDemo {
    // 定义一个 final 方法
    public final void display() {
      System.out.println("This is a final method.");
    }
}

class Main extends FinalDemo {
  // 尝试重写 final 方法
  public final void display() {
    System.out.println("The final method is overridden.");
  }

  public static void main(String[] args) {
    Main obj = new Main();
    obj.display();
  }
}
```

这里，`FinalDemo` 类中的 `display()` 方法是 `final` 的，因此不能在 `Main` 类中被重写。尝试这样做会产生编译错误：

```plaintext title="编译错误" icon="<Atom/>"
display() in Main cannot override display() in FinalDemo
  public final void display() {
                    ^
  overridden method is final
```

## 3. Java 中的 final 类

`final` 类不能被任何其他类继承。例如：

```java
// 定义一个 final 类
final class FinalClass {
  public void display() {
    System.out.println("This is a final method.");
  }
}

// 尝试继承 final 类
class Main extends FinalClass {
  public void display() {
    System.out.println("The final method is overridden.");
  }

  public static void main(String[] args) {
    Main obj = new Main();
    obj.display();
  }
}
```

在这个示例中，`FinalClass` 被声明为 `final`，因此 `Main` 不能继承它。尝试继承它会导致编译错误：

```plaintext
cannot inherit from final FinalClass
class Main extends FinalClass {
                   ^
```
