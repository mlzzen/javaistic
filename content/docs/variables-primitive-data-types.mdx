## Java 数据类型

顾名思义，数据类型规定了可以存储在 [Java 变量](/docs/variables-and-literals) 中的数据类型。

Java 是一种静态类型语言。这意味着所有变量在使用前都必须先声明。

```java
int speed;
```

这里，`speed` 是一个变量，该变量的数据类型是 `int`。

`int` 数据类型决定了 `speed` 变量只能存放整数。

Java 编程语言中预定义了 8 种数据类型，称为基本数据类型。

<Callout>

**注意：** 除了基本数据类型，还有引用类型（对象类型）。

</Callout>

## 8 种基本数据类型

### 1. boolean 类型

- `boolean` 数据类型有两个可能的值：true 或 false。
- 它们通常用于 **true/false** 条件判断。
- **默认值：`false`**。

#### 示例 1：Java `boolean` 数据类型

```java
class Main {
  public static void main(String[] args) {
    boolean flag = true;
    System.out.println(flag); // 输出 true
  }
}
```

### 2. byte 类型

- `byte` 数据类型的取值范围是 **-128** 到 **127**（8 位有符号二进制补码整数）。
- 如果可以确定变量的值在 -128 到 127 之间，就可以用它代替 int 以节省内存。
- **默认值：0**

#### 示例 2：Java `byte` 数据类型

```java
class Main {
  public static void main(String[] args) {
    byte range;
    range = 124;
    System.out.println(range);    // 输出 124
  }
}
```

### 3. short 类型

- Java 中的 `short` 数据类型的取值范围是 **-32768** 到 **32767**（16 位有符号二进制补码整数）。
- 如果可以确定变量的值在 -32768 到 32767 之间，就可以用它代替其他整数数据类型（`int`、`long`）。
- **默认值：0**

#### 示例 3：Java `short` 数据类型

```java
class Main {
  public static void main(String[] args) {
    short temperature;
    temperature = -200;
    System.out.println(temperature); // 输出 -200
  }
}
```

### 4. int 类型

- int 数据类型的取值范围是 **-2<sup>31</sup>** 到 **2<sup>31</sup> -1**（32 位有符号二进制补码整数）。
- 如果你使用的是 Java 8 或更高版本，可以使用无符号 32 位整数。它的最小值为 0，最大值为 2<sup>32-1</sup>。想了解更多，请访问 [如何在 Java 8 中使用无符号整数？](http://stackoverflow.com/questions/25556017/how-to-use-the-unsigned-integer-in-java-8)
- **默认值：0**

#### 示例 4：Java `int` 数据类型

```java
class Main {
  public static void main(String[] args) {
    int range = -4250000;
    System.out.println(range); // 输出 -4250000
  }
}
```

### 5. long 类型

- `long` 数据类型的取值范围是 **-2<sup>63</sup>** 到 **2<sup>63</sup> -1**（64 位有符号二进制补码整数）。
- 如果你使用的是 Java 8 或更高版本，可以使用无符号 64 位整数，其最小值为 0，最大值为 2<sup>64</sup> -1。
- **默认值：0**

#### 示例 5：Java `long` 数据类型

```java
class LongExample {
  public static void main(String[] args) {
    long range = -42332200000L;
    System.out.println(range); // 输出 -42332200000
  }
}
```

注意 `-42332200000` 末尾使用的 `L`。它表示这是一个 `long` 类型的整数字面量。你将在本文后面了解整数字面量。

### 6. double 类型

- `double` 数据类型是双精度 64 位浮点数。
- 它绝不应该用于货币等需要精确值的场景。
- **默认值：0.0（0.0d）**

#### 示例 6：Java `double` 数据类型

```java
class Main {
  public static void main(String[] args) {
    double number = -42.3;
    System.out.println(number); // 输出 -42.3
  }
}
```

### 7. float 类型

- `float` 数据类型是单精度 32 位浮点数。如果你感兴趣，可以进一步了解 [单精度与双精度浮点数](http://stackoverflow.com/questions/801117/whats-the-difference-between-a-single-precision-and-double-precision-floating-p)。
- 它绝不应该用于货币等需要精确值的场景。
- **默认值：0.0（0.0f）**

#### 示例 7：Java `float` 数据类型

```java highlight=3
class Main {
  public static void main(String[] args) {
    float number = -42.3f;
    System.out.println(number); // 输出 -42.3
  }
}
```

注意，在上面的程序中我们使用了 `-42.3f` 而不是 `-42.3`。这是因为 `-42.3` 是一个 `double` 字面量。
要告诉编译器把 `-42.3` 当作 `float` 而不是 `double`，你需要使用 `f` 或 `F`。
如果你想了解单精度和双精度，请访问 Java 单精度和双精度浮点数。

### 8. char 类型

- 它是 16 位 Unicode 字符。
- `char` 数据类型的最小值是 `'\u0000'`（0），最大值是 `'\uffff'`。
- **默认值：'\u0000'**

#### 示例 8：Java `char` 数据类型

```java
class Main {
  public static void main(String[] args) {
    char letter = '\u0051';
    System.out.println(letter); // 输出 Q
  }
}
```

这里，Q 的 Unicode 值是 `\u0051`。因此，我们得到的输出是 Q。

再看一个例子：

```java
class Main {
  public static void main(String[] args) {
    char letter1 = '9';
    System.out.println(letter1); // 输出 9
    char letter2 = 65;
    System.out.println(letter2); // 输出 A
  }
}
```

这里，我们把 9 作为字符（用单引号指定）赋给了 letter1 变量。而 letter2 变量被赋值为整数 65（没有单引号）。

因此，输出中打印的是 A。这是因为 Java 把字符当作整数类型处理，而 A 的 ASCII 值是 65。想进一步了解 ASCII，请访问“什么是 ASCII 码？”。

## 字符串类型

Java 还通过 java.lang.String 类支持字符串。Java 中的字符串不是基本类型，而是对象。例如：

```java
String myString = "Java Programming";
```

这里，myString 是 String 类的一个对象。想了解更多，请访问 [Java 字符串](/docs/string)。
