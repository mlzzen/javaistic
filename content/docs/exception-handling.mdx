异常处理是 Java 中一项强大的机制，它让你能够优雅地处理运行时错误，确保程序不会意外崩溃。程序不必突然终止，而是可以从错误中恢复并继续执行。

## 什么是异常？

异常是在程序执行期间发生、并打断程序正常流程的意外事件。例如：

- 除以零
- 访问越界的数组元素
- 打开一个不存在的文件
- 网络连接失败

## Java 中的异常层次结构

```
                    Object
                      |
                  Throwable
                   /      \
               Error    Exception
                         /      \
                RuntimeException  Checked Exceptions
                (Unchecked)       (IOException, etc.)
```

### 异常的类型

1. **受检异常**：必须在编译期处理（例如 IOException、SQLException）
2. **非受检异常**：运行时异常，可以选择性处理（例如 NullPointerException、ArrayIndexOutOfBoundsException）
3. **错误**：应用程序不应当尝试处理的严重问题（例如 OutOfMemoryError）

## 使用 try-catch 进行基本的异常处理

`try-catch` 块用于在 Java 中处理异常。

### 语法

```java
try {
    // 可能抛出异常的代码
} catch (ExceptionType e) {
    // 处理异常的代码
}
```

### 示例：处理 ArithmeticException

```java
class Main {
    public static void main(String[] args) {
        try {
            int a = 10;
            int b = 0;
            int result = a / b; // 这里会抛出 ArithmeticException
            System.out.println("Result: " + result);
        } catch (ArithmeticException e) {
            System.out.println("Error: Cannot divide by zero!");
            System.out.println("Exception message: " + e.getMessage());
        }

        System.out.println("Program continues...");
    }
}
```

**输出：**

```plaintext
Error: Cannot divide by zero!
Exception message: / by zero
Program continues...
```

## 多个 catch 块

你可以使用多个 catch 块来处理不同类型的异常。

```java
class Main {
    public static void main(String[] args) {
        try {
            int[] numbers = {1, 2, 3};
            System.out.println(numbers[5]); // ArrayIndexOutOfBoundsException

            int result = 10 / 0; // ArithmeticException

        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Array index out of bounds: " + e.getMessage());
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error: " + e.getMessage());
        } catch (Exception e) {
            System.out.println("General exception: " + e.getMessage());
        }
    }
}
```

<Callout>

**注意：** 更具体的异常类型应该排在更笼统的异常类型之前捕获。`Exception` 类应当放在最后一个 catch 块，因为它是所有异常的父类。

</Callout>

## finally 块

`finally` 块包含的代码无论是否发生异常都会执行。它通常用于清理操作。

```java
class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 2;
            System.out.println("Result: " + result);
        } catch (ArithmeticException e) {
            System.out.println("Exception caught: " + e.getMessage());
        } finally {
            System.out.println("This always executes!");
        }

        System.out.println("Program ends");
    }
}
```

**输出：**

```plaintext
Result: 5
This always executes!
Program ends
```

### 示例：配合 finally 处理文件

```java
import java.io.*;

class FileExample {
    public static void main(String[] args) {
        FileReader file = null;
        try {
            file = new FileReader("test.txt");
            // 读取文件操作
            System.out.println("File opened successfully");
        } catch (FileNotFoundException e) {
            System.out.println("File not found: " + e.getMessage());
        } finally {
            // 清理：关闭文件
            if (file != null) {
                try {
                    file.close();
                    System.out.println("File closed");
                } catch (IOException e) {
                    System.out.println("Error closing file: " + e.getMessage());
                }
            }
        }
    }
}
```

## throw 关键字

`throw` 关键字用于显式抛出一个异常。

```java
class AgeValidator {
    static void validateAge(int age) {
        if (age < 18) {
            throw new IllegalArgumentException("Age must be 18 or older");
        }
        System.out.println("Age is valid: " + age);
    }

    public static void main(String[] args) {
        try {
            validateAge(16);
        } catch (IllegalArgumentException e) {
            System.out.println("Exception: " + e.getMessage());
        }

        validateAge(25); // 这次会正常执行
    }
}
```

**输出：**

```plaintext
Exception: Age must be 18 or older
Age is valid: 25
```

## throws 关键字

`throws` 关键字用在方法签名中，用于声明该方法可能抛出某些异常。

```java
import java.io.*;

class FileHandler {
    // 方法声明了它可能抛出 IOException
    static void readFile(String fileName) throws IOException {
        FileReader file = new FileReader(fileName);
        BufferedReader reader = new BufferedReader(file);
        System.out.println(reader.readLine());
        reader.close();
    }

    public static void main(String[] args) {
        try {
            readFile("example.txt");
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}
```

## 自定义异常

你可以通过继承 `Exception` 类或其子类来创建自己的异常类。

```java
// 自定义异常类
class InsufficientFundsException extends Exception {
    public InsufficientFundsException(String message) {
        super(message);
    }
}

class BankAccount {
    private double balance;

    public BankAccount(double balance) {
        this.balance = balance;
    }

    public void withdraw(double amount) throws InsufficientFundsException {
        if (amount > balance) {
            throw new InsufficientFundsException(
                "Insufficient funds. Available: $" + balance + ", Requested: $" + amount
            );
        }
        balance -= amount;
        System.out.println("Withdrawal successful. New balance: $" + balance);
    }

    public double getBalance() {
        return balance;
    }
}

class Main {
    public static void main(String[] args) {
        BankAccount account = new BankAccount(1000.0);

        try {
            account.withdraw(500.0);  // 成功
            account.withdraw(600.0);  // 这里会抛出自定义异常
        } catch (InsufficientFundsException e) {
            System.out.println("Transaction failed: " + e.getMessage());
        }
    }
}
```

**输出：**

```plaintext
Withdrawal successful. New balance: $500.0
Transaction failed: Insufficient funds. Available: $500.0, Requested: $600.0
```

## 常见异常类型

### 1. NullPointerException

当试图访问 null 引用的方法或字段时抛出。

```java
class Main {
    public static void main(String[] args) {
        try {
            String str = null;
            int length = str.length(); // NullPointerException
        } catch (NullPointerException e) {
            System.out.println("Null pointer error: " + e.getMessage());
        }
    }
}
```

### 2. ArrayIndexOutOfBoundsException

当使用无效的索引访问数组时抛出。

```java
class Main {
    public static void main(String[] args) {
        try {
            int[] numbers = {1, 2, 3};
            System.out.println(numbers[5]); // 无效索引
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Array index error: " + e.getMessage());
        }
    }
}
```

### 3. NumberFormatException

当试图把无效的字符串转换成数字时抛出。

```java
class Main {
    public static void main(String[] args) {
        try {
            String str = "abc";
            int number = Integer.parseInt(str); // 无效的数字格式
        } catch (NumberFormatException e) {
            System.out.println("Number format error: " + e.getMessage());
        }
    }
}
```

## 异常处理最佳实践

### 1. 使用具体的异常类型

```java
// 推荐做法
try {
    // 代码
} catch (FileNotFoundException e) {
    // 处理文件未找到
} catch (IOException e) {
    // 处理其他 IO 错误
}

// 避免
try {
    // 代码
} catch (Exception e) {
    // 过于笼统
}
```

### 2. 不要忽略异常

```java
// 错误做法
try {
    // 有风险的代码
} catch (Exception e) {
    // 空的 catch 块 —— 千万别这么做！
}

// 正确做法
try {
    // 有风险的代码
} catch (Exception e) {
    logger.error("Error occurred: " + e.getMessage(), e);
    // 或者做恰当的处理
}
```

### 3. 使用 try-with-resources 管理资源

```java
// 自动资源管理（Java 7+）
try (FileReader file = new FileReader("example.txt");
     BufferedReader reader = new BufferedReader(file)) {

    String line = reader.readLine();
    System.out.println(line);

} catch (IOException e) {
    System.out.println("File error: " + e.getMessage());
}
// 文件会自动关闭
```

## 实战示例：用户输入校验

```java
import java.util.Scanner;

class UserInputValidator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            try {
                System.out.print("Enter your age: ");
                String input = scanner.nextLine();

                int age = Integer.parseInt(input);

                if (age < 0) {
                    throw new IllegalArgumentException("Age cannot be negative");
                }

                if (age > 150) {
                    throw new IllegalArgumentException("Age seems unrealistic");
                }

                System.out.println("Valid age: " + age);
                break; // 输入成功后退出循环

            } catch (NumberFormatException e) {
                System.out.println("Please enter a valid number!");
            } catch (IllegalArgumentException e) {
                System.out.println("Invalid age: " + e.getMessage());
            }
        }

        scanner.close();
    }
}
```

## 异常传播

当异常在某个方法中未被处理时，它会沿着调用栈向上传播。

```java
class ExceptionPropagation {
    static void method1() {
        int result = 10 / 0; // ArithmeticException 在这里抛出
    }

    static void method2() {
        method1(); // 异常从 method1 向上传播
    }

    static void method3() {
        try {
            method2(); // 异常从 method2 向上传播
        } catch (ArithmeticException e) {
            System.out.println("Exception caught in method3: " + e.getMessage());
        }
    }

    public static void main(String[] args) {
        method3();
        System.out.println("Program continues...");
    }
}
```

## 需要记住的要点

- 使用 `try-catch` 块优雅地处理异常
- 总是先处理具体的异常，再处理笼统的异常
- 使用 `finally` 块执行清理操作
- 使用 `throw` 显式抛出异常
- 在方法签名中使用 `throws` 声明可能抛出的异常
- 通过继承 `Exception` 类创建自定义异常
- 永远不要用空的 catch 块忽略异常
- 使用 try-with-resources 实现自动的资源管理
- 未被处理的异常会沿着调用栈向上传播

<Callout>

**最佳实践：** 在应用程序中合适的层次处理异常。如果在某个位置你无法有意义地处理异常，就不要过早地捕获它。

</Callout>
