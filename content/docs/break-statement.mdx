在使用循环时，有时我们希望跳过循环内的某些语句，或者不再检查测试表达式而立即终止循环。

这时就会用到 `break` 和 `continue` 语句。你将在下一节教程中学习 Java continue 语句。

Java 中的 break 语句会立即终止循环，程序的控制权转移到循环之后的下一条语句。

它几乎总是与决策语句（Java if...else 语句）一起使用。

下面是 Java 中 break 语句的语法：

```java
break;
```

## 示例 1：Java break 语句

Java while 循环用于重复执行特定代码，直到满足某个条件为止。while 循环的语法是：

```java
class Test {
    public static void main(String[] args) {

        // for 循环
        for (int i = 1; i <= 10; ++i) {

            // 如果 i 的值为 5，循环终止
            if (i == 5) {
                break;
            }
            System.out.println(i);
        }
    }
}
```

#### 输出

```plaintext
1
2
3
4
```

在上面的程序中，我们使用 `for` 循环在每次迭代中打印 i 的值。想了解 for 循环的工作原理，请访问 Java `for` 循环。这里请注意这条语句：

```java
if (i == 5) {
    break;
}
```

这意味着当 `i` 的值等于 5 时，循环终止。因此我们得到的输出中只包含小于 5 的值。
