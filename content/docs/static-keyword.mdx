## Java 中的 `static` 关键字是什么？

在 Java 中，如果我们要访问类的成员，必须先创建该类的一个实例。但有些情况下，我们希望不创建任何变量就能访问类的成员。
在这些情况下，就可以使用 Java 中的 `static` 关键字。如果想不创建类的实例就访问类的成员，我们需要把这些类成员声明为 static。
Java 中的 `Math` 类几乎所有成员都是 static 的。因此，我们可以不创建 Math 类的实例就访问它的成员。

### 示例 1

```java
public class Main {
    public static void main( String[] args ) {

        // 访问 Math 类的方法
        System.out.println("Absolute value of -12 =  " + Math.abs(-12));
        System.out.println("Value of PI = " + Math.PI);
        System.out.println("Value of E = " + Math.E);
        System.out.println("2^2 = " + Math.pow(2,2));
    }
}
```

### 输出：

```bash
Absolute value of -12 = 12
Value of PI = 3.141592653589793
Value of E = 2.718281828459045
2^2 = 4.0
```

在上面的示例中，我们没有创建 Math 类的任何实例，却能够访问它的方法：`abs()` 和 `pow()`，以及变量：`PI` 和 `E`。

之所以可以这样，是因为 Math 类的方法和变量都是 static 的。
