Java 中的构造方法与方法类似，它会在创建类的对象时被调用。

与 Java 方法不同，构造方法的名称与类名相同，而且没有任何返回类型。例如：

```java
class Test {
  Test() {
    // 构造方法体
  }
}
```

这里，`Test()` 就是一个构造方法。它的名称与类名相同，并且没有返回类型。

## 示例：Java 构造方法

```java
class Main {
  private String name;

  // 构造方法
  Main() {
    System.out.println("Constructor Called:");
    name = "Javaistic";
  }

  public static void main(String[] args) {

    // 创建 Main 类的对象时
    // 会调用构造方法
    Main obj = new Main();
    System.out.println("The name is " + obj.name);
  }
}
```

### 输出：

```plaintext
Constructor Called:
The name is Javaistic
```

在上面的示例中，我们创建了一个名为 `Main()` 的构造方法。

在构造方法内部，我们初始化了 `name` [变量](/docs/variables-literals)的值。

注意创建 `Main` 类对象的那条语句。

```java
Main obj = new Main();
```

这里，创建对象时会调用 `Main()` 构造方法，并初始化 name 变量的值。

因此，程序把 name 变量的值打印为 Javaistic。

## 构造方法的类型

在 Java 中，构造方法可以分为三种类型：

- [无参构造方法](#1-java-no-arg-constructors)
- [带参构造方法](#2-java-parameterized-constructor)
- [默认构造方法](#3-java-default-constructor)

## 1. Java 无参构造方法

与方法类似，Java 构造方法可以有参数（实参），也可以没有参数。

如果构造方法不接收任何参数，它就被称为无参构造方法。例如：

```java
private Constructor() {
   // 构造方法体
}
```

### 示例：Java private 无参构造方法

```java
class Main {

  int i;

  // 无参构造方法
  private Main() {
    i = 5;
    System.out.println("Constructor is called");
  }

  public static void main(String[] args) {

    // 调用无参构造方法
    Main obj = new Main();
    System.out.println("Value of i: " + obj.i);
  }
}
```

#### 输出：

```plaintext
Constructor is called
Value of i: 5
```

在上面的示例中，我们创建了一个构造方法 Main()。
这里，构造方法不接收任何参数，因此它被称为无参构造方法。
注意我们把构造方法声明为 private。
一旦构造方法被声明为 private，它就无法从类外部访问。

因此，使用私有构造方法时，无法从类外部创建对象。
这里，我们是在同一个类内部创建对象。

所以程序能够访问这个构造方法。想了解更多，请访问 Java 实现私有构造方法。
不过，如果我们想在类外部创建对象，就需要把构造方法声明为 public。

### 示例：Java public 无参构造方法

```java
class Company {
  String name;

  // public 构造方法
  public Company() {
    name = "Javaistic";
  }
}

class Main {
  public static void main(String[] args) {

    // 在另一个类中创建对象
    Company obj = new Company();
    System.out.println("Company name = " + obj.name);
  }
}
```

#### 输出

```plaintext
Company name = Javaistic
```

## 2. Java 带参构造方法

Java 构造方法也可以接收一个或多个参数。这样的构造方法被称为带参构造方法（带参数的构造方法）。

### 示例：带参构造方法

```java
class Main {

  String languages;

  // 接收单个值的构造方法
  Main(String lang) {
    languages = lang;
    System.out.println(languages + " Programming Language");
  }

  public static void main(String[] args) {

    // 传入单个值调用构造方法
    Main obj1 = new Main("Java");
    Main obj2 = new Main("Python");
    Main obj3 = new Main("C");
  }
}
```

#### 输出

```plaintext
Java Programming Language
Python Programming Language
C Programming Language
```

在上面的示例中，我们创建了一个名为 `Main()` 的构造方法。
这里，构造方法接收一个参数。注意这个表达式：

```java
Main obj1 = new Main("Java");
```

这里，我们把单个值传给了构造方法。
根据传入的实参，language 变量会在构造方法内部被初始化。

## 3. Java 默认构造方法

如果我们没有创建任何构造方法，Java 编译器会在程序执行期间自动创建一个无参构造方法。
这个构造方法被称为默认构造方法。

### 示例：默认构造方法

```java
class Main {

  int a;
  boolean b;

  public static void main(String[] args) {

    // 调用默认构造方法
    Main obj = new Main();

    System.out.println("Default Value:");
    System.out.println("a = " + obj.a);
    System.out.println("b = " + obj.b);
  }
}
```

#### 输出

```plaintext
Default Value:
a = 0
b = false
```

这里，我们没有创建任何构造方法。

因此，Java 编译器会自动创建默认构造方法。

默认构造方法会用默认值初始化所有未初始化的实例变量。

|   类型   |    默认    |   值   |
| :-----: | :-------: | :----: |
| boolean |           | false  |
|  byte   |           |   0    |
|  short  |           |   0    |
|   int   |           |   0    |
|  long   |           |   0L   |
|  char   |           | \u0000 |
|  float  |           |  0.0f  |
| double  |           |  0.0d  |
| object  |   引用    |  null  |

想了解更多，请访问 [Java 数据类型](/docs/variables-primitive-data-types)。
在上面的程序中，变量 a 和 b 分别被初始化为默认值 `0` 和 `false`。

上面的程序等价于：

```java
class Main {

  int a;
  boolean b;

   Main() {
    a = 0;
    b = false;
  }

  public static void main(String[] args) {
    // 调用构造方法
    Main obj = new Main();

    System.out.println("Default Value:");
    System.out.println("a = " + obj.a);
    System.out.println("b = " + obj.b);
  }
}
```

#### 输出

```plaintext
Default Value:
a = 0
b = false
```

### 关于 Java 构造方法的重要说明

当你实例化对象时，构造方法会被隐式调用。

创建构造方法的两条规则是：

1. 构造方法的名称应与类名相同。
2. Java 构造方法不能有返回类型。

如果一个类没有构造方法，Java 编译器会在运行时自动创建一个默认构造方法。默认构造方法会用默认值初始化实例变量。例如，int 变量会被初始化为 0

### 构造方法的类型：

无参构造方法 - 不接收任何实参的构造方法
带参构造方法 - 接收实参的构造方法
默认构造方法 - 如果没有显式定义，由 Java 编译器自动创建的构造方法。
构造方法不能是 abstract、static 或 final。
构造方法可以被重载，但不能被重写。

## Java 中的构造方法重载

与 Java 方法重载类似，我们也可以创建两个或更多参数不同的构造方法。这被称为构造方法重载。

### 示例：Java 构造方法重载

```java
class Main {

  String language;

  // 无参构造方法
  Main() {
    this.language = "Java";
  }

  // 带一个参数的构造方法
  Main(String language) {
    this.language = language;
  }

  public void getName() {
    System.out.println("Programming Language: " + this.language);
  }

  public static void main(String[] args) {

    // 调用无参构造方法
    Main obj1 = new Main();

    // 调用带一个参数的构造方法
    Main obj2 = new Main("Python");

    obj1.getName();
    obj2.getName();
  }
}
```

#### 输出

```plaintext
Programming Language: Java
Programming Language: Python
```

在上面的示例中，我们有两个构造方法：`Main()` 和 `Main(String language)`。

这里，两个构造方法用不同的值初始化 language 变量。
根据创建对象时传入的参数，会调用不同的构造方法，并赋予不同的值。
也可以从一个构造方法调用另一个构造方法。想了解更多，请访问 Java 从一个构造方法调用另一个构造方法。
