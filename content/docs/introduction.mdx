**Java** 是一门强大的**通用编程语言**。它被用来**开发桌面和移动应用、大数据处理、嵌入式系统**等等。据拥有 **Java** 的公司 **Oracle** 称，**全球有 30 亿台设备运行 Java**，这使 Java 成为最受欢迎的编程语言之一。

要开始学习 Java 编程，请访问 [Java 教程](/programs/introduction)。

## Java 编程的特性

#### 1. Java 与平台无关

Java 的创建理念是“一次编写，到处运行”（WORA）。你在一个平台（操作系统）上编写的 Java 代码，无需任何修改就能在其他平台上运行。

#### 2. 面向对象的语言

面向对象方法是流行的编程风格之一。在面向对象编程中，复杂问题通过创建对象被拆分成更小的集合。这使得 Java 代码可复用、在设计上有优势，并且更容易维护。

#### 3. Java 很快

早期版本的 Java 曾因速度慢而受到批评。然而，新版本的 Java 是最快的编程语言之一。

一段经过良好优化的 Java 代码，速度几乎与 C/C++ 等底层语言相当，并且远比 Python、PHP 等语言快。

#### 4. Java 很健壮

健壮的意思就是强大。Java 之所以健壮，是因为：

它使用强大的内存管理机制。

- 没有指针，避免了安全问题。
- Java 中有自动垃圾回收，它在 Java 虚拟机上运行，用于清除应用程序不再使用的对象。
- Java 中有异常处理和类型检查机制。所有这些都让 Java 变得健壮。

#### 5. Java 是安全的

Java 处理的一些高级安全特性包括：

- 为开发和运行应用程序提供安全的平台
- 自动内存管理减少了内存损坏和漏洞

#### 6. 庞大的标准库

Java 被广泛使用的原因之一，是它拥有庞大的标准库。Java 环境中在不同包下提供了数百个类和方法，来帮助像我们这样的软件开发者。例如，

- `java.lang` - 用于字符串、数组等高级特性
- `java.util` - 用于数据结构、正则表达式、日期和时间函数等
- `java.io` - 用于文件 i/o、异常处理等

## Java 编程的应用领域

据拥有 Java 的公司 Oracle 称，全球有 30 亿台设备运行 Java，这使 Java 成为最受欢迎的编程语言之一。

#### 1. Android 应用

使用 Android SDK（软件开发工具包）的 Java 编程语言通常用于开发 Android 应用。

#### 2. Web 应用

Java 通过 Servlet、Struts 或 JSP 来创建 Web 应用。一些用 Java 编写的热门 Web 应用有 Google.com、Facebook.com、eBay.com、LinkedIn.com 等。

#### 3. 大数据处理

你可以使用 Hadoop（用 Java 编写）等流行的软件框架来处理大数据。

#### 4. 嵌入式设备

Oracle 的 Java Embedded 技术为数十亿嵌入式设备（如电视、SIM 卡、蓝光光盘播放器等）提供平台和运行环境。

除了这些应用，Java 还用于游戏开发、科学应用（如自然语言处理）以及许多其他领域。

## 如何学习用 Java 编程？

#### 1. 通过 Javaistic 学习 Java

Javaistic 提供了一整套易于跟随的 Java 教程，并配有合适的示例。这些教程面向完全没有 Java 编程语言基础知识的绝对初学者。

#### 2. 通过书籍学习 Java

通过书籍学习编程始终是个好主意。你能从书中获得编程概念的全貌，这在其他地方可能找不到。

以下是我们个人推荐的一些书。

- [**Java: The Complete Reference, Ninth Edition**](http://amzn.to/2mAdN34) - 涵盖 Java 的一切，包括语法、关键字等
- [**Thinking in Java (4th Edition)**](http://amzn.to/2mkvCCK) - 如果你是从其他编程语言转过来，这本最合适
- [**Java 8 Pocket Guide: Instant Help for Java Programmers**](http://amzn.to/2mEszGG) - 最适合快速查找答案

#### 3. 从官方 Java 文档学习

拥有 Java 的公司 Oracle 提供了高质量的 Java 文档。官方文档会持续更新。不过，对初学者来说，它可能不是最容易跟随的教程。

## Java 编程最佳实践

到现在你一定很想学 Java 了。不过，在学习 Java 之前，有一些技巧和最佳实践值得遵循。

- <b>不要像读小说一样读 Java 教程和示例</b>：在编程上进步的唯一方法就是大量写代码。
- <b>用正确的方式学习 Java 语言</b>：如果你是从另一种编程语言（比如 C#）转过来的，不要在 Java 里写 C# 风格的代码。另外，可以看看这篇文章：<a href="http://www.ibm.com/developerworks/library/j-perry-writing-good-java-code/index.html">如何写出好的 Java 代码？</a>
- <b>加入 Java 社区</b>：一旦你掌握了编写简单 Java 程序的门道，就加入 Java 社区和论坛。然后试着解决其他程序员的 Java 问题。这是拓展 Java 知识的好方法。而且，当你卡住时也能得到帮助。

## 结语

学 Java 不会错。它广泛的应用领域，使它成为充满机会与可能的语言。
