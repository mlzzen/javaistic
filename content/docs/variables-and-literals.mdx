## Java 变量

变量是内存中用于存放数据的（存储）位置。

为了标明这个存储区域，每个变量都应该有一个唯一的名称（标识符）。想了解更多，请访问 [Java 标识符](https://javaistic.vercel.app/java-introduction/keywords-identifiers)。

---

### 在 Java 中创建变量

下面是在 Java 中创建变量的方式：

```java
int speedLimit = 80;

```

这里，`speedLimit` 是一个 `int` 数据类型的变量，我们给它赋值为 **80**。

`int` 数据类型表示这个变量只能存放整数。
想了解更多，请访问 [Java 数据类型](/docs/variables-primitive-data-types)。

在上面的示例中，我们在声明变量的同时给它赋了值。不过，这并不是必须的。

你可以把声明变量和给变量赋值分开进行。例如：

```java
int speedLimit;
speedLimit = 80;
```

### 更改变量的值

变量的值可以在程序中被更改，这正是它被称为“变量”的原因。例如：

```java
int speedLimit = 80;
... .. ...
speedLimit = 90;
```

这里，`speedLimit` 的值最初是 **80**。后来，我们把它改成了 **90**。

不过，在 Java 中，我们不能在同一个作用域内改变变量的数据类型。

什么是变量作用域？

现在先不用担心它。只要记住，我们不能这样做：

```java
int speedLimit = 80;
... .. ...
float speedLimit;
```

想了解更多，请访问：[在 Java 中我能更改变量的声明类型吗](http://stackoverflow.com/questions/27092245/can-i-change-declaration-type-for-a-variable-in-java)？

### Java 中的变量命名规则

Java 编程语言有一套自己的变量命名规则和约定。你需要了解以下内容：

- Java 区分大小写。因此，`age` 和 `AGE` 是两个不同的变量。例如：

```java
int age = 24;
int AGE = 25;

System.out.println(age); // 输出 24
System.out.println(AGE); // 输出 25
```

- 变量名必须以**字母**、**下划线** **\_** 或**美元符号** **$** 开头。例如：

```java
int age; // 合法名称，也是良好实践
int _age; // 合法，但不是良好实践
int $age; // 合法，但不是良好实践
```

- 变量名不能以数字开头。例如：

```java
int 1age; // 无效的变量
```

- 变量名不能包含空白字符。例如：

```java
int my age; // 无效的变量
```

这里，如果我们需要使用由多个单词组成的变量名，第一个单词全部用小写字母，其后每个单词的首字母大写。例如，`myAge`。

- 创建变量时，要选择一个有意义的名称。例如，`score`、`number`、`level` 就比 `s`、`n`、`l` 这样的变量名更有意义。
- 如果变量名只有一个单词，请全部使用小写字母。例如，用 `speed` 比用 `SPEED` 或 `sPEED` 更好。

Java 编程语言中有 4 种变量：

- **实例变量（非静态字段）**
- **类变量（静态字段）**
- **局部变量**
- **参数**

## Java 字面量

字面量是用来表示固定值的数据。它们可以直接在代码中使用。例如：

```java
int a = 1;
float b = 2.5;
char c = 'F';
```

这里，`1`、`2.5` 和 `'F'` 都是字面量。

下面是 Java 中不同类型的字面量。

---

### 1. 布尔字面量

在 Java 中，布尔字面量用于初始化布尔数据类型。它们可以存储两个值：true 和 false。例如：

```java
boolean flag1 = false;
boolean flag2 = true;
```

这里，`false` 和 `true` 是两个布尔字面量。

---

### 2. 整数字面量

整数字面量是不带任何小数部分或指数部分的数值（与数字相关）。Java 中有 4 种整数字面量：

1. 二进制（基数为 2）
2. 十进制（基数为 10）
3. 八进制（基数为 8）
4. 十六进制（基数为 16）

例如：

```java
// 二进制
int binaryNumber = 0b10010;
// 八进制
int octalNumber = 027;

// 十进制
int decNumber = 34;

// 十六进制
int hexNumber = 0x2F; // 0x 表示十六进制
// 二进制
int binNumber = 0b10010; // 0b 表示二进制

```

在 Java 中，二进制以 **0b** 开头，八进制以 **0** 开头，十六进制以 **0x** 开头。

<p className="mt-4" />

<Callout>

**注意：** 整数字面量用于初始化整数类型的变量，例如 `byte`、`short`、`int` 和 `long`。

</Callout>

---

### 3. 浮点字面量

浮点字面量是带有小数形式或指数形式的数字字面量。例如：

```java
class Main {
  public static void main(String[] args) {
    double myDouble = 3.4;
    float myFloat = 3.4F;

    // 3.445*10^2
    double myDoubleScientific = 3.445e2;

    System.out.println(myDouble); // 输出 3.4
    System.out.println(myFloat); // 输出 3.4
    System.out.println(myDoubleScientific); // 输出 344.5
  }
}
```

<p className="mt-4" />

<Callout>

**注意：** 浮点字面量用于初始化 `float` 和 `double` 类型的变量。

</Callout>

---

### 4. 字符字面量

字符字面量是用单引号括起来的 Unicode 字符。例如：

```java
char letter = 'a';
```

这里，`a` 是字符字面量。

我们也可以把转义序列用作字符字面量。例如，**\b**（退格）、**\t**（制表符）、**\n**（换行）等。

---

### 5. 字符串字面量

字符串字面量是用双引号括起来的一串字符。例如：

```java
String str1 = "Java Programming";
String str2 = "Javaistic";
```

这里，`Java Programming` 和 `Javaistic` 是两个字符串字面量。
