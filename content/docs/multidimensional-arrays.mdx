在了解多维数组之前，请确保你已经了解 Java 数组。

多维数组就是数组的数组。多维数组的每个元素本身也是一个数组。例如，

```java
int[][] a = new int[3][4];
```

这里，我们创建了一个名为 a 的多维数组。它是一个二维数组，最多可以容纳 12 个元素，

[Java 中的二维数组]
二维数组

记住，Java 使用从零开始的索引，也就是说，Java 中数组的索引从 0 开始，而不是 1。

让我们再看一个多维数组的例子。这次我们将创建一个三维数组。例如，

```java
String[][][] data = new String[3][4][2];
```

这里，data 是一个三维数组，最多可以容纳 24（3*4*2）个 [String](/docs/string) 类型的元素。

### 如何在 Java 中初始化二维数组？

以下是在 Java 中初始化二维数组的方法。

```java
int[][] a = {
    {1, 2, 3},
    {4, 5, 6, 9},
    {7},
};
```

如你所见，多维数组的每个元素本身也是一个数组。而且，与 C/C++ 不同，Java 中多维数组的每一行可以具有不同的长度。

[Java 中长度可变的二维数组示例]
二维数组的初始化

### 示例：二维数组

```java
class MultidimensionalArray {
    public static void main(String[] args) {

        // 创建一个二维数组
        int[][] a = {
            {1, 2, 3},
            {4, 5, 6, 9},
            {7},
        };

        // 计算每一行的长度
        System.out.println("Length of row 1: " + a[0].length);
        System.out.println("Length of row 2: " + a[1].length);
        System.out.println("Length of row 3: " + a[2].length);
    }
}
```

#### 输出：

```plaintext
Length of row 1: 3
Length of row 2: 4
Length of row 3: 1
```

在上面的示例中，我们创建了一个名为 a 的多维数组。由于多维数组的每个组成部分也是数组（`a[0]`、`a[1]` 和 `a[2]` 也是数组）。

这里，我们使用 `length` 属性来计算每一行的长度。

### 示例：使用循环打印二维数组的所有元素

```java
class MultidimensionalArray {
    public static void main(String[] args) {

        int[][] a = {
            {1, -2, 3},
            {-4, -5, 6, 9},
            {7},
        };

        for (int i = 0; i < a.length; ++i) {
            for(int j = 0; j < a[i].length; ++j) {
                System.out.println(a[i][j]);
            }
        }
    }
}
```

#### 输出：

```plaintext
1
-2
3
-4
-5
6
9
7
```

我们也可以使用 [for...each 循环](/docs/enhanced-for-loop) 来访问多维数组的元素。例如，

```java
class MultidimensionalArray {
    public static void main(String[] args) {

        // 创建一个二维数组
        int[][] a = {
            {1, -2, 3},
            {-4, -5, 6, 9},
            {7},
        };

        // 第一个 for...each 循环访问二维数组中的
        // 各个数组
        for (int[] innerArray: a) {
            // 第二个 for...each 循环访问该行中的每个元素
            for(int data: innerArray) {
                System.out.println(data);
            }
        }
    }
}
```

输出：

```plaintext
1
-2
3
-4
-5
6
9
7
```

在上面的示例中，我们创建了一个名为 `a` 的二维数组。然后我们使用 `for` 循环和 `for...each` 循环来访问数组的每个元素。

### 如何在 Java 中初始化三维数组？

让我们看看如何在 Java 中使用三维数组。我们可以像初始化二维数组那样初始化三维数组。例如，

```java
// test 是一个三维数组
int[][][] test = {
        {
          {1, -2, 3},
          {2, 3, 4}
        },
        {
          {-4, -5, 6, 9},
          {1},
          {2, 3}
        }
};
```

基本上，三维数组就是二维数组的数组。三维数组的每一行长度也可以像二维数组那样各不相同。

### 示例：三维数组

```java
class ThreeArray {
    public static void main(String[] args) {

        // 创建一个三维数组
        int[][][] test = {
            {
              {1, -2, 3},
              {2, 3, 4}
            },
            {
              {-4, -5, 6, 9},
              {1},
              {2, 3}
            }
        };

        // 用 for..each 循环遍历三维数组的元素
        for (int[][] array2D: test) {
            for (int[] array1D: array2D) {
                for(int item: array1D) {
                    System.out.println(item);
                }
            }
        }
    }
}
```

#### 输出：

```plaintext
1
-2
3
2
3
4
-4
-5
6
9
1
2
3
```
