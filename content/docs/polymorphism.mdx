多态是面向对象编程（OOP）的核心原则之一。“polymorphism”一词源自希腊语，意思是“多种形态”。在 Java 中，多态允许把不同类型的对象当作某个共同基础类型的对象来处理，同时仍然保留它们各自特有的行为。

## 什么是多态？

多态让同一个接口能够代表不同的底层数据类型。它让你可以编写能处理多种类型对象的代码，只要这些对象共享同一个接口或父类。

## Java 中多态的类型

### 1. 编译时多态（静态多态）

- **方法重载**
- **运算符重载**（Java 中受限）

### 2. 运行时多态（动态多态）

- **方法重写**
- **动态方法调度**

## 方法重载（编译时多态）

方法重载允许在同一个类中存在多个同名但参数不同的方法。

### 示例：方法重载

```java
class Calculator {
    // 带有 2 个 int 参数的方法
    public int add(int a, int b) {
        return a + b;
    }

    // 带有 3 个 int 参数的方法
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 带有 2 个 double 参数的方法
    public double add(double a, double b) {
        return a + b;
    }

    // 参数类型不同的方法
    public String add(String a, String b) {
        return a + b;
    }
}

class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();

        System.out.println("Add two integers: " + calc.add(5, 3));           // 8
        System.out.println("Add three integers: " + calc.add(5, 3, 2));     // 10
        System.out.println("Add two doubles: " + calc.add(5.5, 3.2));       // 8.7
        System.out.println("Add two strings: " + calc.add("Hello", "World")); // HelloWorld
    }
}
```

## 方法重写（运行时多态）

方法重写允许子类为父类中已经定义的方法提供自己的具体实现。

### 示例：方法重写

```java
class Animal {
    public void makeSound() {
        System.out.println("Animal makes a sound");
    }

    public void move() {
        System.out.println("Animal moves");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Dog barks: Woof! Woof!");
    }

    @Override
    public void move() {
        System.out.println("Dog runs on four legs");
    }
}

class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Cat meows: Meow! Meow!");
    }

    @Override
    public void move() {
        System.out.println("Cat walks gracefully");
    }
}

class Bird extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Bird chirps: Tweet! Tweet!");
    }

    @Override
    public void move() {
        System.out.println("Bird flies in the sky");
    }
}
```

## 运行时多态与动态方法调度

运行时多态通过方法重写和动态方法调度来实现。JVM 会在运行时根据对象的实际类型决定调用哪个方法。

### 示例：运行时多态

```java
class Main {
    public static void main(String[] args) {
        // Animal 类型的引用变量
        Animal animal;

        // 创建不同类型的对象
        animal = new Dog();
        animal.makeSound(); // 狗叫：汪！汪！
        animal.move();      // 狗用四条腿奔跑

        animal = new Cat();
        animal.makeSound(); // 猫叫：喵！喵！
        animal.move();      // 猫优雅地行走

        animal = new Bird();
        animal.makeSound(); // 鸟叫：啾！啾！
        animal.move();      // 鸟在天空中飞翔
    }
}
```

### 多态对象数组

```java
class AnimalShelter {
    public static void main(String[] args) {
        // Animal 引用组成的数组
        Animal[] animals = {
            new Dog(),
            new Cat(),
            new Bird(),
            new Dog(),
            new Cat()
        };

        System.out.println("Animal Shelter Sounds:");
        for (Animal animal : animals) {
            animal.makeSound(); // 多态方法调用
            animal.move();
            System.out.println("---");
        }
    }
}
```

## 实战示例：图形计算器

```java
abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 由子类实现的抽象方法
    public abstract double calculateArea();
    public abstract double calculatePerimeter();

    // 所有图形共有的方法
    public void displayInfo() {
        System.out.println("Shape: " + this.getClass().getSimpleName());
        System.out.println("Color: " + color);
        System.out.println("Area: " + calculateArea());
        System.out.println("Perimeter: " + calculatePerimeter());
    }
}

class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double calculateArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public double calculatePerimeter() {
        return 2 * Math.PI * radius;
    }
}

class Rectangle extends Shape {
    private double length;
    private double width;

    public Rectangle(String color, double length, double width) {
        super(color);
        this.length = length;
        this.width = width;
    }

    @Override
    public double calculateArea() {
        return length * width;
    }

    @Override
    public double calculatePerimeter() {
        return 2 * (length + width);
    }
}

class Triangle extends Shape {
    private double side1, side2, side3;

    public Triangle(String color, double side1, double side2, double side3) {
        super(color);
        this.side1 = side1;
        this.side2 = side2;
        this.side3 = side3;
    }

    @Override
    public double calculateArea() {
        // 使用海伦公式
        double s = (side1 + side2 + side3) / 2;
        return Math.sqrt(s * (s - side1) * (s - side2) * (s - side3));
    }

    @Override
    public double calculatePerimeter() {
        return side1 + side2 + side3;
    }
}

class ShapeCalculator {
    public static void main(String[] args) {
        // 不同图形组成的数组
        Shape[] shapes = {
            new Circle("Red", 5.0),
            new Rectangle("Blue", 4.0, 6.0),
            new Triangle("Green", 3.0, 4.0, 5.0)
        };

        System.out.println("=== Shape Calculator ===\n");

        for (Shape shape : shapes) {
            shape.displayInfo(); // 多态方法调用
            System.out.println();
        }

        // 使用多态计算总面积
        double totalArea = 0;
        for (Shape shape : shapes) {
            totalArea += shape.calculateArea();
        }

        System.out.printf("Total Area of all shapes: %.2f\n", totalArea);
    }
}
```

## 基于接口的多态

接口为实现 Java 中的多态提供了另一种方式。

```java
interface Drawable {
    void draw();
    void resize(double factor);
}

interface Moveable {
    void move(int x, int y);
}

class Circle implements Drawable, Moveable {
    private int x, y;
    private double radius;

    public Circle(int x, int y, double radius) {
        this.x = x;
        this.y = y;
        this.radius = radius;
    }

    @Override
    public void draw() {
        System.out.println("Drawing Circle at (" + x + ", " + y + ") with radius " + radius);
    }

    @Override
    public void resize(double factor) {
        radius *= factor;
        System.out.println("Circle resized. New radius: " + radius);
    }

    @Override
    public void move(int newX, int newY) {
        this.x = newX;
        this.y = newY;
        System.out.println("Circle moved to (" + x + ", " + y + ")");
    }
}

class Square implements Drawable, Moveable {
    private int x, y;
    private double side;

    public Square(int x, int y, double side) {
        this.x = x;
        this.y = y;
        this.side = side;
    }

    @Override
    public void draw() {
        System.out.println("Drawing Square at (" + x + ", " + y + ") with side " + side);
    }

    @Override
    public void resize(double factor) {
        side *= factor;
        System.out.println("Square resized. New side: " + side);
    }

    @Override
    public void move(int newX, int newY) {
        this.x = newX;
        this.y = newY;
        System.out.println("Square moved to (" + x + ", " + y + ")");
    }
}

class GraphicsEditor {
    public static void main(String[] args) {
        // 使用接口实现多态
        Drawable[] drawables = {
            new Circle(10, 20, 5.0),
            new Square(30, 40, 8.0)
        };

        System.out.println("=== Drawing Shapes ===");
        for (Drawable shape : drawables) {
            shape.draw();
            shape.resize(1.5);
        }

        System.out.println("\n=== Moving Shapes ===");
        Moveable[] moveables = {
            new Circle(0, 0, 3.0),
            new Square(0, 0, 4.0)
        };

        for (Moveable shape : moveables) {
            shape.move(100, 200);
        }
    }
}
```

## 方法重载与方法重写的区别

| 对比项              | 方法重载                                    | 方法重写                                              |
| ------------------- | ----------------------------------------------------- | -------------------------------------------------------------- |
| **定义**      | 同名但参数不同的多个方法 | 子类为父类方法提供具体实现 |
| **继承**     | 不需要                                          | 需要                                                       |
| **参数**      | 必须不同                                     | 必须相同                                                   |
| **返回类型**     | 可以不同                                      | 必须相同（或协变）                                    |
| **访问修饰符** | 可以不同                                      | 不能更严格                                     |
| **绑定**         | 编译时                                          | 运行时                                                        |
| **性能**     | 更快                                                | 稍慢                                                |

## 多态的好处

### 1. 代码复用

```java
// 一个方法可以处理多种类型
public void feedAnimal(Animal animal) {
    animal.makeSound(); // 适用于 Dog、Cat、Bird 等
}
```

### 2. 灵活性与可扩展性

```java
// 无需修改现有代码即可轻松添加新类型
class Fish extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Fish makes bubbles");
    }
}
// 无需修改使用 Animal 的现有方法
```

### 3. 可维护性

```java
// 实现的变化不会影响调用方代码
Animal pet = new Dog(); // 可以轻松换成 Cat 或 Bird
pet.makeSound(); // 方法调用保持不变
```

## 进阶示例：插件系统

```java
interface Plugin {
    String getName();
    void execute();
    String getVersion();
}

class LoggerPlugin implements Plugin {
    @Override
    public String getName() {
        return "Logger Plugin";
    }

    @Override
    public void execute() {
        System.out.println("Logging system information...");
    }

    @Override
    public String getVersion() {
        return "1.0.0";
    }
}

class SecurityPlugin implements Plugin {
    @Override
    public String getName() {
        return "Security Plugin";
    }

    @Override
    public void execute() {
        System.out.println("Running security scan...");
    }

    @Override
    public String getVersion() {
        return "2.1.0";
    }
}

class PluginManager {
    private Plugin[] plugins;

    public PluginManager(Plugin[] plugins) {
        this.plugins = plugins;
    }

    public void runAllPlugins() {
        System.out.println("=== Plugin Manager ===");
        for (Plugin plugin : plugins) {
            System.out.println("Loading: " + plugin.getName() + " v" + plugin.getVersion());
            plugin.execute(); // 多态方法调用
            System.out.println("---");
        }
    }
}

class Application {
    public static void main(String[] args) {
        Plugin[] plugins = {
            new LoggerPlugin(),
            new SecurityPlugin()
        };

        PluginManager manager = new PluginManager(plugins);
        manager.runAllPlugins();
    }
}
```

## 需要记住的要点

- **多态**允许把不同类型的对象统一对待
- **方法重载**是编译时多态（方法名相同、参数不同）
- **方法重写**是运行时多态（子类提供具体实现）
- **动态方法调度**在运行时决定调用哪个方法
- 使用**抽象类**和**接口**来定义共同行为
- 多态促进**代码复用**和**灵活性**
- 实际调用的方法由**对象类型**决定，而不是引用类型
- 多态对于编写**可扩展**、**可维护**的代码至关重要

**最佳实践：** 用多态来编写依赖抽象（接口或抽象类）而不是具体实现的代码。这样你的代码会更灵活，也更容易扩展。
