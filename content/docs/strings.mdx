在 Java 中，字符串是表示字符序列的对象。`String` 类是 Java 编程中最常用的类之一。

## 什么是 Java 中的字符串？

字符串是字符的序列。在 Java 中，字符串是 `String` 类的对象。与基本数据类型不同，字符串是引用类型。

```java
String message = "Hello, World!";
```

这里，`message` 是一个字符串变量，保存着值“Hello, World!”。

## 在 Java 中创建字符串

在 Java 中创建字符串主要有两种方式：

### 1. 字符串字面量

```java
String str1 = "Java Programming";
String str2 = "Javaistic";
```

### 2. 使用 new 关键字

```java
String str1 = new String("Java Programming");
String str2 = new String("Javaistic");
```

<Callout>

**注意：** 字符串字面量存储在字符串池中以提高内存效率，而使用 `new` 关键字创建的字符串存储在堆内存中。

</Callout>

## 字符串方法

Java 提供了许多用于字符串操作的有用方法：

### 1. length() 方法

返回字符串中的字符数。

```java
class Main {
    public static void main(String[] args) {
        String str = "Java";
        System.out.println("Length: " + str.length()); // 输出：4
    }
}
```

### 2. charAt() 方法

返回指定索引处的字符。

```java
class Main {
    public static void main(String[] args) {
        String str = "Java";
        System.out.println("Character at index 1: " + str.charAt(1)); // 输出：a
    }
}
```

### 3. substring() 方法

提取字符串的一部分。

```java
class Main {
    public static void main(String[] args) {
        String str = "Java Programming";
        System.out.println("Substring: " + str.substring(5)); // 输出：Programming
        System.out.println("Substring: " + str.substring(0, 4)); // 输出：Java
    }
}
```

### 4. toLowerCase() 和 toUpperCase()

将字符串转换为小写或大写。

```java
class Main {
    public static void main(String[] args) {
        String str = "Java Programming";
        System.out.println("Lowercase: " + str.toLowerCase()); // java programming
        System.out.println("Uppercase: " + str.toUpperCase()); // JAVA PROGRAMMING
    }
}
```

### 5. indexOf() 方法

返回某个字符或子字符串第一次出现处的索引。

```java
class Main {
    public static void main(String[] args) {
        String str = "Java Programming";
        System.out.println("Index of 'a': " + str.indexOf('a')); // 输出：1
        System.out.println("Index of 'Programming': " + str.indexOf("Programming")); // 输出：5
    }
}
```

## 字符串比较

### 1. 使用 equals() 方法

```java
class Main {
    public static void main(String[] args) {
        String str1 = "Java";
        String str2 = "Java";
        String str3 = new String("Java");

        System.out.println(str1.equals(str2)); // true
        System.out.println(str1.equals(str3)); // true
    }
}
```

### 2. 使用 equalsIgnoreCase() 方法

```java
class Main {
    public static void main(String[] args) {
        String str1 = "Java";
        String str2 = "JAVA";

        System.out.println(str1.equalsIgnoreCase(str2)); // true
    }
}
```

### 3. 使用 compareTo() 方法

```java
class Main {
    public static void main(String[] args) {
        String str1 = "Apple";
        String str2 = "Banana";

        System.out.println(str1.compareTo(str2)); // 负值（Apple < Banana）
    }
}
```

<Callout>

**重要：** 永远不要使用 `==` 运算符来比较字符串。它比较的是引用，而不是内容。

</Callout>

## 字符串拼接

### 1. 使用 + 运算符

```java
class Main {
    public static void main(String[] args) {
        String firstName = "John";
        String lastName = "Doe";
        String fullName = firstName + " " + lastName;
        System.out.println(fullName); // John Doe
    }
}
```

### 2. 使用 concat() 方法

```java
class Main {
    public static void main(String[] args) {
        String str1 = "Hello";
        String str2 = " World";
        String result = str1.concat(str2);
        System.out.println(result); // Hello World
    }
}
```

## StringBuilder 和 StringBuffer

当你需要执行大量字符串操作时，请使用 `StringBuilder` 或 `StringBuffer` 以获得更好的性能。

### StringBuilder 示例

```java
class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        sb.append("Java");
        sb.append(" ");
        sb.append("Programming");

        System.out.println(sb.toString()); // Java Programming

        // 在指定位置插入
        sb.insert(5, "is ");
        System.out.println(sb.toString()); // Java is Programming

        // 删除字符
        sb.delete(5, 8);
        System.out.println(sb.toString()); // Java Programming
    }
}
```

### StringBuffer 与 StringBuilder

| 特性     | StringBuilder | StringBuffer |
| ------------- | ---------------------------- | --------------------------- |
| 线程安全     | 非线程安全                  | 线程安全                    |
| 性能     | 更快                        | 更慢                        |
| 使用场景     | 单线程应用                  | 多线程应用                  |

## 字符串格式化

### 1. 使用 printf() 方法

```java
class Main {
    public static void main(String[] args) {
        String name = "John";
        int age = 25;
        System.out.printf("Name: %s, Age: %d%n", name, age);
        // 输出：Name: John, Age: 25
    }
}
```

### 2. 使用 String.format() 方法

```java
class Main {
    public static void main(String[] args) {
        String name = "Alice";
        double score = 95.5;
        String formatted = String.format("Student: %s, Score: %.1f", name, score);
        System.out.println(formatted); // Student: Alice, Score: 95.5
    }
}
```

## 常见字符串操作示例

```java
class StringExample {
    public static void main(String[] args) {
        String text = "  Java Programming Language  ";

        // 移除空白字符
        String trimmed = text.trim();
        System.out.println("Trimmed: '" + trimmed + "'");

        // 拆分字符串
        String[] words = trimmed.split(" ");
        for (String word : words) {
            System.out.println("Word: " + word);
        }

        // 替换字符
        String replaced = trimmed.replace("Java", "Python");
        System.out.println("Replaced: " + replaced);

        // 检查字符串是否包含子字符串
        boolean contains = trimmed.contains("Programming");
        System.out.println("Contains 'Programming': " + contains);

        // 检查字符串是否以某内容开头或结尾
        boolean startsWith = trimmed.startsWith("Java");
        boolean endsWith = trimmed.endsWith("Language");
        System.out.println("Starts with 'Java': " + startsWith);
        System.out.println("Ends with 'Language': " + endsWith);
    }
}
```

**输出：**

```plaintext
Trimmed: 'Java Programming Language'
Word: Java
Word: Programming
Word: Language
Replaced: Python Programming Language
Contains 'Programming': true
Starts with 'Java': true
Ends with 'Language': true
```

## 需要记住的要点

- Java 中的字符串是**不可变**的：一旦创建，就不能更改
- 频繁修改字符串时使用 `StringBuilder`
- 始终使用 `.equals()` 方法比较字符串内容
- 字符串字面量存储在字符串池中以提高内存效率
- 使用 `.trim()` 去除开头和结尾的空白字符
- `String` 类提供了许多有用的操作方法

<Callout>

**性能提示：** 拼接大量字符串时，请使用 `StringBuilder` 而不是 `+` 运算符，以避免创建多个中间字符串对象。

</Callout>
