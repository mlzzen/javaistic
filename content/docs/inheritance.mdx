继承是面向对象编程（OOP）的基本概念之一。它允许一个类继承另一个类的属性和方法，从而提高代码复用性，并在类之间建立关系。

## Java 中的继承是什么？

继承是一种机制：一个新类（子类，child class 或 subclass）可以继承已有类（父类，parent class 或 superclass）的属性和方法。子类可以使用父类的方法和字段，也可以添加自己的方法和字段。

```java
class Animal {  // 父类（超类）
    String name;

    void eat() {
        System.out.println(name + " is eating");
    }
}

class Dog extends Animal {  // 子类
    void bark() {
        System.out.println(name + " is barking");
    }
}
```

## extends 关键字

`extends` 关键字用于在类之间建立继承关系。子类通过继承扩展父类。

### 语法

```java
class ChildClass extends ParentClass {
    // 子类主体
}
```

### 示例：基本继承

```java
class Vehicle {
    String brand;
    int speed;

    void displayInfo() {
        System.out.println("Brand: " + brand);
        System.out.println("Speed: " + speed + " km/h");
    }

    void start() {
        System.out.println("Vehicle is starting...");
    }
}

class Car extends Vehicle {
    int doors;

    void honk() {
        System.out.println("Car is honking!");
    }
}

class Main {
    public static void main(String[] args) {
        Car myCar = new Car();
        myCar.brand = "Toyota";
        myCar.speed = 180;
        myCar.doors = 4;

        // 使用继承来的方法
        myCar.displayInfo();
        myCar.start();

        // 使用汽车特有的方法
        myCar.honk();
    }
}
```

**输出：**

```plaintext
Brand: Toyota
Speed: 180 km/h
Vehicle is starting...
Car is honking!
```

## 继承的类型

### 1. 单继承

一个类继承另一个类。

```java
class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}
```

### 2. 多级继承

一个类继承另一个类，而那个类又继承自另一个类。

```java
class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Mammal extends Animal {
    void walk() {
        System.out.println("Mammal is walking");
    }
}

class Dog extends Mammal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();   // 来自 Animal 类
        dog.walk();  // 来自 Mammal 类
        dog.bark();  // 来自 Dog 类
    }
}
```

### 3. 层次继承

多个类继承同一个父类。

```java
class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Cat is meowing");
    }
}
```

<Callout>

**注意：**Java 不支持类的多重继承（一个类不能 extends 多个类），但可以通过接口实现多重继承。

</Callout>

## super 关键字

`super` 关键字用于指向直接父类的对象。它有以下几种用法：

### 1. 访问父类方法

```java
class Animal {
    void display() {
        System.out.println("I am an animal");
    }
}

class Dog extends Animal {
    void display() {
        super.display(); // 调用父类方法
        System.out.println("I am a dog");
    }
}

class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.display();
    }
}
```

**输出：**

```plaintext
I am an animal
I am a dog
```

### 2. 访问父类变量

```java
class Animal {
    String color = "white";
}

class Dog extends Animal {
    String color = "brown";

    void displayColors() {
        System.out.println("Dog color: " + color);        // brown
        System.out.println("Animal color: " + super.color); // white
    }
}
```

### 3. 调用父类构造方法

```java
class Animal {
    String name;

    Animal(String name) {
        this.name = name;
        System.out.println("Animal constructor called");
    }
}

class Dog extends Animal {
    String breed;

    Dog(String name, String breed) {
        super(name); // 调用父类构造方法
        this.breed = breed;
        System.out.println("Dog constructor called");
    }

    void display() {
        System.out.println("Name: " + name + ", Breed: " + breed);
    }
}

class Main {
    public static void main(String[] args) {
        Dog dog = new Dog("Buddy", "Golden Retriever");
        dog.display();
    }
}
```

**输出：**

```plaintext
Animal constructor called
Dog constructor called
Name: Buddy, Breed: Golden Retriever
```

## 方法重写

方法重写允许子类为父类中已定义的方法提供专门的具体实现。

### 方法重写的规则

1. 方法名必须与父类中的方法名相同
2. 方法的参数必须与父类中的相同
3. 必须存在 IS-A 关系（继承）

### 示例：方法重写

```java
class Animal {
    void makeSound() {
        System.out.println("Animal makes a sound");
    }

    void sleep() {
        System.out.println("Animal is sleeping");
    }
}

class Dog extends Animal {
    @Override
    void makeSound() {
        System.out.println("Dog barks");
    }

    // sleep() 方法被原样继承
}

class Cat extends Animal {
    @Override
    void makeSound() {
        System.out.println("Cat meows");
    }
}

class Main {
    public static void main(String[] args) {
        Animal animal1 = new Dog();
        Animal animal2 = new Cat();

        animal1.makeSound(); // 输出：Dog barks
        animal2.makeSound(); // 输出：Cat meows

        animal1.sleep();     // 输出：Animal is sleeping
    }
}
```

### @Override 注解

`@Override` 注解用于表明某个方法正在被重写。它有助于在编译时发现错误。

```java
class Parent {
    void display() {
        System.out.println("Parent display");
    }
}

class Child extends Parent {
    @Override
    void display() { // 这个注解确保重写是正确的
        System.out.println("Child display");
    }
}
```

## 访问修饰符与继承

不同的访问修饰符会影响成员的继承方式：

| 访问修饰符 | 同一个类 | 同一个包 | 子类 | 其他包 |
| --------------- | ---------- | ------------ | -------- | ------------- |
| private         | ✓          | ✗            | ✗        | ✗             |
| default         | ✓          | ✓            | ✓\*      | ✗             |
| protected       | ✓          | ✓            | ✓        | ✗             |
| public          | ✓          | ✓            | ✓        | ✓             |

\*仅当子类位于同一个包中

### 示例：protected 成员

```java
class Parent {
    protected String message = "Hello from Parent";

    protected void display() {
        System.out.println("Protected method in Parent");
    }
}

class Child extends Parent {
    void show() {
        System.out.println(message); // 可以访问 protected 成员
        display(); // 可以访问 protected 方法
    }
}
```

## 继承中的构造方法链

创建子类对象时，构造方法会按从父类到子类的顺序依次调用。

```java
class GrandParent {
    GrandParent() {
        System.out.println("GrandParent constructor");
    }
}

class Parent extends GrandParent {
    Parent() {
        System.out.println("Parent constructor");
    }
}

class Child extends Parent {
    Child() {
        System.out.println("Child constructor");
    }
}

class Main {
    public static void main(String[] args) {
        Child child = new Child();
    }
}
```

**输出：**

```plaintext
GrandParent constructor
Parent constructor
Child constructor
```

## 实战示例：员工管理系统

```java
class Employee {
    protected String name;
    protected int id;
    protected double salary;

    public Employee(String name, int id, double salary) {
        this.name = name;
        this.id = id;
        this.salary = salary;
    }

    public void displayInfo() {
        System.out.println("ID: " + id);
        System.out.println("Name: " + name);
        System.out.println("Salary: $" + salary);
    }

    public double calculateBonus() {
        return salary * 0.05; // 5% 奖金
    }
}

class Manager extends Employee {
    private int teamSize;

    public Manager(String name, int id, double salary, int teamSize) {
        super(name, id, salary);
        this.teamSize = teamSize;
    }

    @Override
    public void displayInfo() {
        super.displayInfo();
        System.out.println("Team Size: " + teamSize);
        System.out.println("Role: Manager");
    }

    @Override
    public double calculateBonus() {
        return salary * 0.15; // 管理者的奖金为 15%
    }
}

class Developer extends Employee {
    private String programmingLanguage;

    public Developer(String name, int id, double salary, String language) {
        super(name, id, salary);
        this.programmingLanguage = language;
    }

    @Override
    public void displayInfo() {
        super.displayInfo();
        System.out.println("Programming Language: " + programmingLanguage);
        System.out.println("Role: Developer");
    }
}

class Main {
    public static void main(String[] args) {
        Manager manager = new Manager("Alice", 101, 75000, 5);
        Developer developer = new Developer("Bob", 102, 60000, "Java");

        System.out.println("Manager Details:");
        manager.displayInfo();
        System.out.println("Bonus: $" + manager.calculateBonus());

        System.out.println("\nDeveloper Details:");
        developer.displayInfo();
        System.out.println("Bonus: $" + developer.calculateBonus());
    }
}
```

## 需要记住的要点

- 使用 `extends` 关键字建立继承关系
- 子类继承父类所有非 private 成员
- 使用 `super` 关键字访问父类成员
- 方法重写允许子类提供专门的具体实现
- 使用 `@Override` 注解确保正确重写方法
- 构造方法链会自动从父类到子类依次执行
- Java 的类支持单继承
- `private` 成员不会被继承
- `protected` 成员可以被子类访问

<Callout>

**最佳实践：**重写方法时始终使用 `@Override` 注解，这样可以尽早发现错误，并提高代码可读性。

</Callout>
