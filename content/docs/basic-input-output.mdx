## Java 输出

在 Java 中，你可以简单地使用

```java
System.out.println(); or

System.out.print(); or

System.out.printf();
```

把输出发送到标准输出（屏幕）。

这里，

- `System` 是一个类
- `out` 是一个 `public` `static` 字段：它接收输出数据。

如果你不理解也没关系。我们会在后面的章节中讨论 `class`、`public` 和 `static`。

让我们看一个输出一行文本的例子。

```java
class AssignmentOperator {
    public static void main(String[] args) {

        System.out.println("Java programming is interesting.");
    }
}
```

**输出：**

```plaintext
Java programming is interesting.
```

这里，我们使用了 `println()` 方法来显示这个字符串。

## println()、print() 和 printf() 的区别

- `print()` - 它打印引号内的字符串。
- `println()` - 它和 `print()` 方法一样打印引号内的字符串。之后光标会移动到下一行的开头。
- `printf()` - 它提供字符串格式化功能。

### 示例：print() 和 println()

```java
class Output {
    public static void main(String[] args) {

        System.out.println("1. println ");
        System.out.println("2. println ");

        System.out.print("1. print ");
        System.out.print("2. print");
    }
}
```

**输出：**

```plaintext
1. println
2. println
1. print 2. print
```

在上面的示例中，我们展示了 `print()` 和 `println()` 方法的工作方式。要了解 `printf()` 方法，请访问 Java [**printf()**](https://www.cs.colostate.edu/~cs160/.Summer16/resources/Java_printf_method_quick_reference.pdf)。

### 示例：打印变量和字面量

```java
class Variables {
    public static void main(String[] args) {

        Double number = -10.6;

        System.out.println(5);
        System.out.println(number);
    }
}
```

运行程序时，输出将是：

```plaintext
5
-10.6
```

这里你可以看到，我们没有使用引号。这是因为要显示整数、变量等内容时，我们不使用引号。

### 示例：打印拼接的字符串

```java
class PrintVariables {
    public static void main(String[] args) {

        Double number = -10.6;

        System.out.println("I am " + "awesome.");
        System.out.println("Number = " + number);
    }
}
```

**输出：**

```java
I am awesome.
Number = -10.6
```

在上面的示例中，请注意这一行，

```java
System.out.println("I am " + "awesome.");
```

这里，我们使用了 + 运算符来拼接（连接）两个字符串：`"I am "` 和 `"awesome."`。

此外，还有这一行，

```java
System.out.println("Number = " + number);
```

这里，首先对变量 `number` 的值求值。然后，把这个值与字符串 `"Number = "` 拼接起来。

## Java 输入

Java 提供了多种从用户那里获取输入的方式。不过，在本教程中，你将学习使用 `Scanner` 类的对象来获取用户输入。

为了使用 `Scanner` 的对象，我们需要导入 `java.util.Scanner` 包。

```java
import java.util.Scanner;
```

要了解更多关于在 Java 中导入包的内容，请访问 [Java 导入包]()。

然后，我们需要创建 `Scanner` 类的对象。我们可以用这个对象来接收用户的输入。

```java
// 创建 Scanner 的对象
Scanner input = new Scanner(System.in);

// 接收用户的输入
int number = input.nextInt();
```

### 示例：从用户处获取整数输入

```java
import java.util.Scanner;

class Input {
    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.print("Enter an integer: ");
        int number = input.nextInt();
        System.out.println("You entered " + number);

        // 关闭 scanner 对象
        input.close();
    }
}
```

**输出：**

```plaintext
Enter an integer: 23
You entered 23
```

在上面的示例中，我们创建了一个名为 `input` 的 `Scanner` 类对象。然后我们调用 `Scanner` 类的 `nextInt()` 方法来获取用户输入的整数。

类似地，我们可以使用 `nextLong()`、`nextFloat()`、`nextDouble()` 和 `next()` 方法，分别从用户那里获取 `long`、`float`、`double` 和 `string` 类型的输入。

<Callout>
  **注意：** 我们使用了 `close()` 方法来关闭该对象。建议在取完输入后关闭 scanner 对象。
</Callout>

### 示例：获取 float、double 和 String 输入

```java
import java.util.Scanner;

class Input {
    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        // 获取 float 输入
        System.out.print("Enter float: ");
        float myFloat = input.nextFloat();
        System.out.println("Float entered = " + myFloat);

        // 获取 double 输入
        System.out.print("Enter double: ");
        double myDouble = input.nextDouble();
        System.out.println("Double entered = " + myDouble);

        // 获取 String 输入
        System.out.print("Enter text: ");
        String myString = input.next();
        System.out.println("Text entered = " + myString);
    }
}
```

**输出：**

```plaintext
Enter float: 2.343
Float entered = 2.343
Enter double: -23.4
Double entered = -23.4
Enter text: Hey!
Text entered = Hey!
```

如前所述，还有其他几种获取用户输入的方式。要了解更多关于 `Scanner` 的内容，请访问 Java Scanner。
