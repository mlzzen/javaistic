## Java 表达式

Java 表达式由变量、运算符、字面量和方法调用组成。要了解更多关于方法调用的内容，请访问 Java 方法。例如，

```java
int score;
score = 90;
```

这里，`score = 90` 是一个返回 `int` 的表达式。再看另一个例子，

```java
Double a = 2.2, b = 3.4, result;
result = a + b - 3.4;
```

这里，`a + b - 3.4` 是一个表达式。

```java
if (number1 == number2)
System.out.println("Number 1 is larger than number 2");
```

这里，`number1 == number2` 是一个返回布尔值的表达式。类似地，`"Number 1 is larger than number 2"` 是一个字符串表达式。

## Java 语句

在 Java 中，每条语句都是一个完整的执行单元。例如，

```java
int score = 9*5;
```

这里，我们有一条语句。这条语句的完整执行过程包括把整数 `9` 和 `5` 相乘，然后把结果赋给变量 `score`。

在上面的语句中，我们有一个表达式 `9 * 5`。在 Java 中，表达式是语句的一部分。

### 表达式语句

我们可以通过在表达式末尾加上 `;` 来把表达式转换成语句。这类语句称为表达式语句。例如，

```java
// 表达式
number = 10
// 语句
number = 10;
```

在上面的示例中，我们有一个表达式 `number = 10`。这里，通过添加一个分号（`;`），我们把该表达式转换成了语句（`number = 10;`）。

再看另一个例子，

```java
// 表达式
++number
// 语句
++number;
```

类似地，`++number` 是表达式，而 `++number;` 是语句。

### 声明语句

在 Java 中，声明语句用于声明变量。例如，

```java
Double tax = 9.5;
```

上面的语句声明了一个变量 tax，并将其初始化为 9.5。

## Java 代码块

代码块是由一对花括号 { } 括起来的一组语句（零条或多条）。例如，

```java
class Main {
    public static void main(String[] args) {

        String band = "Beatles";

        if (band == "Beatles") { // 代码块开始
            System.out.print("Hey ");
            System.out.print("Jude!");
        } // 代码块结束
    }
}
```

输出：

```plaintext
Hey Jude!
```

在上面的示例中，我们有一个代码块 `if {....}`。

这里，代码块内部有两条语句：

- `System.out.print("Hey ");`
- `System.out.print("Jude!");`

不过，代码块也可以不包含任何语句。看看下面的例子，

```java
class Main {
    public static void main(String[] args) {

        if (10 > 5) { // 代码块开始

        } // 代码块结束
    }
}
```

这是一个合法的 Java 程序。这里，我们有一个代码块 `if {...}`。不过，这个代码块内部没有任何语句。

```java
class AssignmentOperator {
    public static void main(String[] args) {  // 代码块开始

    } // 代码块结束
}
```

这里，我们有一个代码块 `public static void main() {...}`。不过，与上面的示例类似，这个代码块也没有任何语句。
