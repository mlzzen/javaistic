`switch` 语句允许我们在众多选项中执行一个代码块。

Java 中 `switch` 语句的语法是：

```java
switch (expression) {

  case value1:
    // code
    break;

  case value2:
    // code
    break;

  ...
  ...

  default:
    // default statements
  }
```

## switch-case 语句如何工作？

`expression` 只求值一次，并与每个 case 的值进行比较。

- 如果 `expression` 与 `value1` 匹配，则执行 `case value1` 的代码。同样，如果 `expression` 与 `value2` 匹配，则执行 `case value2` 的代码。
- 如果没有任何匹配，则执行 **default 分支**的代码。

<Callout>

**注意：** switch-case 语句的工作方式与 [Java if...else...if 阶梯](/docs/if-else-statement#3-java-if-else-if-statement) 类似。不过，`switch` 语句的语法更简洁，读写起来也容易得多。

</Callout>

### 示例：Java switch 语句

#### 输入

```java
// 检查尺寸的 Java 程序
// 使用 switch...case 语句

class Main {
  public static void main(String[] args) {

    int number = 44;
    String size;

    // 用 switch 语句检查尺寸
    switch (number) {

      case 29:
        size = "Small";
        break;

      case 42:
        size = "Medium";
        break;

      // 匹配 week 的值
      case 44:
        size = "Large";
        break;

      case 48:
        size = "Extra Large";
        break;

      default:
        size = "Unknown";
        break;

    }
    System.out.println("Size: " + size);
  }
}
```

#### 输出：

```plaintext
Size: Large
```

在上面的示例中，我们使用 switch 语句来查找尺寸。这里，我们有一个变量 `number`。该变量会与每个 case 语句的值进行比较。

由于值与 **44** 匹配，所以执行 `case 44` 的代码。

```java
size = "Large";
break;
```

这里，`size` 变量被赋值为 `Large`。

## Java switch...case 中的 break 语句

注意，我们在每个 case 块中都使用了 break。

```java
 ...
case 29:
  size = "Small";
  break;
...
```

`break` 语句用于终止 **switch-case** 语句。如果不使用 `break`，那么匹配的 case 之后的所有 case 也会被执行。例如，

#### 输入

```java
class Main {
  public static void main(String[] args) {

    int expression = 2;

    // 用 switch 语句检查尺寸
    switch (expression) {
      case 1:
        System.out.println("Case 1");

        // 匹配的 case
      case 2:
        System.out.println("Case 2");

      case 3:
        System.out.println("Case 3");

      default:
        System.out.println("Default case");
    }
  }
}
```

#### 输出

```plaintext
Case 2
Case 3
Default case
```

在上面的示例中，`expression` 与 `case 2` 匹配。这里，我们没有在每个 case 之后使用 break 语句。

因此，`case 2` 之后的所有 case 也会被执行。

这就是为什么需要在匹配的 case 之后使用 `break` 语句来终止 **switch-case** 语句。想了解更多，请访问 Java break 语句。

## Java switch-case 中的 default 分支

switch 语句还包含一个**可选的 default 分支**。当表达式不匹配任何 case 时，就会执行它。例如，

#### 输入

```java
class Main {
  public static void main(String[] args) {

    int expression = 9;

    switch(expression) {

      case 2:
        System.out.println("Small Size");
        break;

      case 3:
        System.out.println("Large Size");
        break;

      // default 分支
      default:
        System.out.println("Unknown Size");
    }
  }
}
```

#### 输出

```plaintext
Unknown Size
```

在上面的示例中，我们创建了一个 **switch-case** 语句。这里，`expression` 的值不匹配任何 case。

因此，执行 **default 分支**内的代码。

```java
default:
  System.out.println("Unknown Size);
```
