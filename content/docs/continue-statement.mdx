在使用循环时，有时你可能想跳过某些语句，或者终止循环。这时就会用到 break 和 continue 语句。

想了解 break 语句，请访问 Java break。这里，我们将学习 continue 语句。

## Java continue

continue 语句会跳过循环（for、while、do...while 等）的当前迭代。

执行 continue 语句后，程序会跳到循环的末尾。然后对测试表达式求值（在 for 循环中则是对更新语句求值）。

下面是 continue 语句的语法。

```java
continue;
```

注意：continue 语句几乎总是用在决策语句（if...else 语句）中。

## Java continue 语句的工作原理

下面介绍 continue 语句在 Java while、do...while 和 for 循环中的工作原理。
Java continue 语句的工作原理

### 示例 1：Java continue 语句

```java
class Main {
  public static void main(String[] args) {

    // for 循环
    for (int i = 1; i <= 10; ++i) {

      // 如果 i 的值在 4 和 9 之间
      // 就执行 continue
      if (i > 4 && i < 9) {
        continue;
      }
      System.out.println(i);
    }
  }
}
```

#### 输出：

```plaintext
1
2
3
4
9
10
```

在上面的程序中，我们使用 for 循环在每次迭代中打印 i 的值。想了解 for 循环的工作原理，请访问 Java for 循环。请注意这条语句：

```java
if (i > 4 && i < 9) {
    continue;
}
```

这里，当 i 的值大于 4 且小于 9 时，就会执行 continue 语句。

于是这些数值对应的打印语句被跳过。因此，输出中跳过了 5、6、7 和 8。

### 示例 2：计算 5 个正数之和

```java
import java.util.Scanner;

class Main {
  public static void main(String[] args) {

    Double number, sum = 0.0;
    // 创建一个 Scanner 对象
    Scanner input = new Scanner(System.in);

    for (int i = 1; i < 6; ++i) {
      System.out.print("Enter number " + i + " : ");
      // 从用户处获取输入
      number = input.nextDouble();

      // 如果数字为负数
      // 就执行 continue 语句
      if (number <= 0.0) {
        continue;
      }

      sum += number;
    }
    System.out.println("Sum = " + sum);
    input.close();
  }
}
```

#### 输出：

```plaintext
Enter number 1: 2.2
Enter number 2: 5.6
Enter number 3: 0
Enter number 4: -2.4
Enter number 5: -3
Sum = 7.8
```

在上面的示例中，我们使用 for 循环来求 5 个正数之和。请注意这一行：

```java
if (number < 0.0) {
    continue;
}
```

这里，当用户输入负数时，就会执行 continue 语句。这会跳过循环的当前迭代，并把程序的控制权交给循环的更新表达式。

注意：为了从用户处获取输入，我们使用了 Scanner 对象。想了解更多内容，请访问 Java Scanner。
