在计算机编程中，循环用于重复执行某段代码。例如，如果你想显示 100 次消息，就可以使用循环。这只是一个简单的例子；用循环你能做到的事情远不止这些。

在上一节教程中，你学习了 [Java for 循环](./for-loop)。这里，你将学习 `while` 循环和 `do...while` 循环。

## Java while 循环

Java while 循环用于重复执行特定代码，直到满足某个条件为止。while 循环的语法是：

```java
while (testExpression) {
    // 循环体
}
```

这里的含义是：

1. `while` 循环先对括号 `()` 中的 **textExpression** 求值。
2. 如果 **textExpression** 的值为 `true`，就执行 `while` 循环中的代码。
3. 再次对 **textExpression** 求值。
4. 这个过程一直持续，直到 **textExpression** 为 `false`。
5. 当 **textExpression** 的值为 `false` 时，循环停止。

想了解更多关于条件的内容，请访问 [Java 关系运算符](./operators#3-java-relational-operators)和[逻辑运算符](./operators#4-java-logical-operators)。

### 示例 1：显示 1 到 5 的数字

```java
// 显示 1 到 5 的数字的程序

class Main {
  public static void main(String[] args) {

    // 声明变量
    int i = 1, n = 5;

    // 从 1 到 5 的 while 循环
    while(i <= n) {
      System.out.println(i);
      i++;
    }
  }
}
```

#### 输出

```plaintext
1
2
3
4
5
```

这个程序是这样工作的。

| 迭代   | 变量             | 条件：i `<=` n | 动作                            |
| ------ | ---------------- | -------------- | ------------------------------- |
| 第 1 次 | `i = 1` `n = 5`  | `true`         | 打印 `1`。`i` 增加到 **2**。    |
| 第 2 次 | `i = 2` `n = 5 ` | `true`         | 打印 `2`。`i` 增加到 **3**。    |
| 第 3 次 | `i = 3` `n = 5`  | `true`         | 打印 `3`。`i` 增加到 **4**。    |
| 第 4 次 | `i = 4` `n = 5`  | `true`         | 打印 `4`。`i` 增加到 **5**。    |
| 第 5 次 | `i = 5` ` n = 5` | `true`         | 打印 `5`。`i` 增加到 **6**。    |
| 第 6 次 | `i = 6` `n = 5`  | `false`        | 循环终止                        |

### 示例 2：只求正数之和

```java
// 求正数之和的 Java 程序
import java.util.Scanner;

class Main {
  public static void main(String[] args) {

    int sum = 0;

    // 创建 Scanner 类的对象
    Scanner input = new Scanner(System.in);

    // 从用户处获取整数输入
    System.out.println("Enter a number");
    int number = input.nextInt();

    // while 循环持续执行
    // 直到输入的数字为正数
    while (number >= 0) {
      // 只累加正数
      sum += number;

      System.out.println("Enter a number");
      number = input.nextInt();
    }

    System.out.println("Sum = " + sum);
    input.close();
  }
}
```

#### 输出

```plaintext
Enter a number
25
Enter a number
9
Enter a number
5
Enter a number
-3
Sum = 39
```

在上面的程序中，我们使用 [Scanner 类](./scanner)从用户处获取输入。这里，`nextInt()` 从用户处读取整数输入。

`while` 循环会一直执行，直到用户输入负数。在每次迭代中，用户输入的数字都会被加到 `sum` 变量上。

当用户输入负数时，循环终止。最后，显示总和。

## Java do...while 循环

`do...while` 循环与 while 循环类似。不过，`do...while` 循环的循环体会在检查测试表达式之前先执行一次。例如，

```java
do {
    // 循环体
} while(textExpression);
```

这里的含义是：

1. 先执行循环体，然后对 **textExpression** 求值。
2. 如果 **textExpression** 的值为 `true`，就再次执行 `do` 语句中的循环体。
3. 再次对 **textExpression** 求值。
4. 如果 **textExpression** 的值为 `true`，就再次执行 `do` 语句中的循环体。
5. 这个过程一直持续，直到 **textExpression** 的值为 false。这时循环停止。

### 示例 3：显示 1 到 5 的数字

```java
// 显示 1 到 5 的数字的 Java 程序

import java.util.Scanner;

// 求 1 到 100 的自然数之和的程序。

class Main {
  public static void main(String[] args) {

    int i = 1, n = 5;

    // 从 1 到 5 的 do...while 循环
    do {
      System.out.println(i);
      i++;
    } while(i <= n);
  }
}
```

#### 输出

```plaintext
1
2
3
4
5
```

这个程序是这样工作的。

| 迭代   | 变量             | 条件：i `<=` n | 动作                            |
| ------ | ---------------- | -------------- | ------------------------------- |
|        | `i = 1` `n = 5`  | 未检查         | 打印 `1`。`i` 增加到 **2**。    |
| 第 1 次 | `i = 2` `n = 5 ` | `true`         | 打印 `2`。`i` 增加到 **3**。    |
| 第 2 次 | `i = 3` `n = 5`  | `true`         | 打印 `3`。`i` 增加到 **4**。    |
| 第 3 次 | `i = 4` `n = 5`  | `true`         | 打印 `4`。`i` 增加到 **5**。    |
| 第 4 次 | `i = 5` ` n = 5` | `true`         | 打印 `5`。`i` 增加到 **6**。    |
| 第 5 次 | `i = 6` `n = 5`  | `false`        | 循环终止                        |

### 示例 4：求正数之和

```java
// 求正数之和的 Java 程序
import java.util.Scanner;

class Main {
  public static void main(String[] args) {

    int sum = 0;
    int number = 0;

    // 创建 Scanner 类的对象
    Scanner input = new Scanner(System.in);

    // do...while 循环持续执行
    // 直到输入的数字为正数
    do {
      // 只累加正数
      sum += number;
      System.out.println("Enter a number");
      number = input.nextInt();
    } while(number >= 0);

    System.out.println("Sum = " + sum);
    input.close();
  }
}
```

#### 输出 1

```plaintext
Enter a number
25
Enter a number
9
Enter a number
5
Enter a number
-3
Sum = 39
```

这里，用户输入一个正数，这个数就会被加到 `sum` 变量上。这个过程一直持续，直到数字为负数。当数字为负数时，循环终止，并显示不包含该负数的总和。

#### 输出 2

```plaintext
Enter a number
-8
Sum is 0
```

这里，用户输入了一个负数。测试条件的结果会是 `false`，但循环内的代码仍然会执行一次。

## 无限 while 循环

如果循环的**条件**始终为 `true`，循环就会无限次执行（直到内存被占满）。例如，

```java
// 无限 while 循环
while(true){
    // 循环体
}
```

## 无限 do...while 循环

下面是无限 `do...while` 循环的一个例子。

```java
// 无限 do...while 循环
int count = 1;
do {
   // 循环体
} while(count == 1)
```

在上面的程序中，**textExpression** 始终为 `true`。因此，循环体会无限次执行。

## for 循环与 while 循环

当迭代次数已知时，使用 `for` 循环。例如，

```java
for (let i = 1; i <=5; ++i) {
   // 循环体
}
```

而 `while` 和 `do...while` 循环通常用于迭代次数未知的情况。例如，

```java
while (condition) {
    // 循环体
}
```
