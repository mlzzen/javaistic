数组是相同类型数据的集合。

例如，如果要存储 100 个人的名字，我们可以创建一个字符串类型的数组来存储这 100 个名字。

```java
String[] array = new String[100];
```

这里，上面的数组最多只能存储 100 个名字。Java 数组中值的数量始终是固定的。

### 如何在 Java 中声明数组？

在 Java 中，声明数组的方式如下。

```java
dataType[] arrayName;
```

- `dataType` - 它可以是 `int`、`char`、`double`、`byte` 等基本数据类型，也可以是 Java 对象
- `arrayName` - 它是一个标识符
  例如，

```java
double[] data;
```

这里，data 是一个可以保存 double 类型值的数组。

但是，这个数组能容纳多少个元素呢？

问得好！要定义数组可以容纳的元素数量，我们必须在 Java 中为数组分配内存。例如，

```java
// 声明一个数组
double[] data;

// 分配内存
data = new double[10];
```

这里，数组可以存储 10 个元素。我们也可以说这个数组的大小或长度为 10。

在 Java 中，我们可以在一条语句中同时声明数组并分配内存。例如，

```java
double[] data = new double[10];
```

### 如何在 Java 中初始化数组？

在 Java 中，我们可以在声明数组的同时对其初始化。例如，

```java
//声明并初始化数组
int[] age = {12, 4, 5, 2, 5};
```

这里，我们创建了一个名为 age 的数组，并用花括号中的值对其进行了初始化。

注意，我们没有提供数组的大小。在这种情况下，Java 编译器会通过统计数组中元素的数量（即 5）来自动确定大小。

在 Java 数组中，每个内存位置都关联着一个数字。这个数字称为数组索引。我们也可以使用索引号在 Java 中初始化数组。例如，

```java
// 声明一个数组
int[] age = new int[5];

// 初始化数组
age[0] = 12;
age[1] = 4;
age[2] = 5;
..
```

<Callout title="注意">
  数组索引始终从 **0** 开始。也就是说，数组的第一个元素位于索引 **0**。如果数组的大小为 `n`，那么数组的最后一个元素位于索引 `n-1`。
</Callout>
