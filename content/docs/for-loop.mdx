在计算机编程中，循环用于重复执行一个代码块。例如，如果你想显示 100 次相同的信息，那么与其把同样的代码输入 100 遍，不如使用循环。

在 Java 中，有三种类型的循环。

- for 循环
- while 循环
- do...while 循环

本教程重点讲解 for 循环。你将在后续教程中了解其他类型的循环。

## Java for 循环

Java 的 `for` 循环用于将一段代码块运行指定的次数。`for` 循环的语法是：

```java
for (initialExpression; testExpression; updateExpression) {
    // body of the loop
}
```

这里，

1. **initialExpression** 初始化或声明变量，并且只执行一次。
2. 对**条件**求值。如果**条件**为 `true`，则执行 `for` 循环的主体。
3. **updateExpression** 更新 **initialExpression** 的值。
4. 再次对**条件**求值。这个过程会一直持续，直到**条件**为 `false`。

要了解更多关于条件的内容，请访问 [Java 关系运算符](operators#3-java-relational-operators) 和 [逻辑运算符](operators#4-java-logical-operators)。

### 示例 1：显示五次文本

#### 输入

```java
// 打印文本 5 次的程序

class Main {
  public static void main(String[] args) {

    int n = 5;
    // for 循环
    for (int i = 1; i <= n; ++i) {
      System.out.println("Java is fun");
    }
  }
}
```

#### 输出

```plaintext
Java is fun
Java is fun
Java is fun
Java is fun
Java is fun
```

这个程序的工作过程如下。

|      迭代       |       变量       | 条件：i `<=` n |                操作                 |
| :-------------: | :--------------: | :------------: | :---------------------------------: |
|     第 1 次     | `i = 1`, `n = 5` |     `true`     | 打印 `Java is fun`，`i` 增加到 **2**。 |
|     第 2 次     | `i = 2`, `n = 5` |     `true`     | 打印 `Java is fun`，`i` 增加到 **3**。 |
|     第 3 次     | `i = 3`, `n = 5` |     `true`     | 打印 `Java is fun`，`i` 增加到 **4**。 |
|     第 4 次     | `i = 4`, `n = 5` |     `true`     | 打印 `Java is fun`，`i` 增加到 **5**。 |
|     第 5 次     | `i = 5`, `n = 5` |     `true`     | 打印 `Java is fun`，`i` 增加到 **6**。 |
|     第 6 次     | `i = 6`, `n = 5` |    `false`     |             循环终止。              |

### 示例 2：显示 1 到 5 的数字

#### 输入

```java
// 打印 1 到 5 的数字的程序

class Main {
  public static void main(String[] args) {

    int n = 5;
    // for 循环
    for (int i = 1; i <= n; ++i) {
      System.out.println(i);
    }
  }
}
```

#### 输出

```plaintext
1
2
3
4
5
```

这个程序的工作过程如下。

|      迭代       |       变量       | 条件：i `<=` n |         操作          |
| :-------------: | :--------------: | :------------: | :--------------------: |
|     第 1 次     | `i = 1`, `n = 5` |     `true`     | 打印 `1`，`i` 增加到 **2**。 |
|     第 2 次     | `i = 2`, `n = 5` |     `true`     | 打印 `2`，`i` 增加到 **3**。 |
|     第 3 次     | `i = 3`, `n = 5` |     `true`     | 打印 `3`，`i` 增加到 **4**。 |
|     第 4 次     | `i = 4`, `n = 5` |     `true`     | 打印 `4`，`i` 增加到 **5**。 |
|     第 5 次     | `i = 5`, `n = 5` |     `true`     | 打印 `5`，`i` 增加到 **6**。 |
|     第 6 次     | `i = 6`, `n = 5` |    `false`     |       循环终止。       |

### 示例 3：显示 n 个自然数之和

```java
// 求 1 到 1000 的自然数之和的程序。

class Main {
  public static void main(String[] args) {

    int sum = 0;
    int n = 1000;

    // for 循环
    for (int i = 1; i <= n; ++i) {
      // for 循环内部的主体
      sum += i;     // sum = sum + i
    }

    System.out.println("Sum = " + sum);
  }
}
```

#### 输出：

```plaintext
Sum = 500500
```

这里，`sum` 的值最初是 **0**。然后，for 循环从 `i = 1 to 1000` 进行迭代。在每次迭代中，`i` 被加到 `sum` 上，同时 `i` 的值增加 **1**。

当 `i` 变成 **1001** 时，测试条件为 `false`，此时 `sum` 将等于 `0 + 1 + 2 + .... + 1000`。

上面这个计算自然数之和的程序也可以写成

```java
// 求 1 到 1000 的自然数之和的程序。

class Main {
  public static void main(String[] args) {

    int sum = 0;
    int n = 1000;

    // for 循环
    for (int i = n; i >= 1; --i) {
      // for 循环内部的主体
      sum += i;     // sum = sum + i
    }

    System.out.println("Sum = " + sum);
  }
}
```

这个程序的输出与**示例 3**相同。

## Java for-each 循环

Java for 循环还有一种替代语法，可以方便地遍历[数组](arrays)和集合。例如，

#### 输入

```java
// 打印数组元素

class Main {
  public static void main(String[] args) {

    // 创建一个数组
    int[] numbers = {3, 7, 5, -5};

    // 遍历数组
    for (int number: numbers) {
       System.out.println(number);
    }
  }
}
```

#### 输出

```plaintext
3
7
5
-5
```

这里，我们使用 **for-each 循环**逐个打印 `numbers` 数组的每个元素。

在循环的第一次迭代中，`number` 为 3；在第二次迭代中，`number` 为 7，依此类推。

想了解更多，请访问 [Java for-each 循环](enhanced-for-loop)。

## Java 无限 for 循环

如果我们把测试表达式设置为永远不会求值为 false 的形式，for 循环就会一直运行下去。这称为无限 for 循环。例如，

#### 输入

```java
// 无限 for 循环

class Infinite {
    public static void main(String[] args) {

        int sum = 0;

        for (int i = 1; i <= 10; --i) {
            System.out.println("Hello");
        }
    }
}
```

这里，测试表达式 `i <= 10` 永远不会是 `false`，Hello 会被反复打印，直到内存耗尽。
