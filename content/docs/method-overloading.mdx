## Java 中的方法重载是什么？

在 Java 中，方法重载允许多个同名但参数列表不同的方法共存于同一个类中。这可以是参数数量不同、参数类型不同，或者两者都不同。重载方法根据传入的参数提供了不同的调用方式，从而带来灵活性。

### 示例：

```java
void func() {}
void func(int a) {}
float func(double a) {}
float func(int a, float b) {}
```

在这个示例中，`func()` 方法以不同的参数配置被重载。虽然返回类型不同，但这并不影响方法重载；重载完全取决于参数。

## 为什么使用方法重载？

设想一个场景：你需要对数字求和，但参数需求可能不同（例如 2 个或 3 个数字）。你可以分别创建 `sum2(int, int)` 和 `sum3(int, int, int)` 这样的方法。不过，使用方法重载可以让方法名保持一致，从而更易读：

```java
int sum(int a, int b) { ... }
int sum(int a, int b, int c) { ... }
```

这里，`sum()` 被重载，以处理不同数量的实参。

## 在 Java 中实现方法重载

方法重载主要通过两种方式实现：

### 1. 改变参数数量

```java
class MethodOverloading {
    private static void display(int a) {
        System.out.println("Argument: " + a);
    }

    private static void display(int a, int b) {
        System.out.println("Arguments: " + a + " and " + b);
    }

    public static void main(String[] args) {
        display(1);
        display(1, 4);
    }
}
```

### 输出

```bash
Argument: 1
Arguments: 1 and 4
```

### 2. 改变参数的数据类型

```java
class MethodOverloading {
    private static void display(int a) {
        System.out.println("Got Integer data.");
    }

    private static void display(String a) {
        System.out.println("Got String object.");
    }

    public static void main(String[] args) {
        display(1);
        display("Hello");
    }
}
```

### 输出

```bash
Got Integer data.
Got String object.
```

## 实际应用示例

在工具类中，你可能会用重载来格式化数字：

```java
class HelperService {
    private String formatNumber(int value) {
        return String.format("%d", value);
    }

    private String formatNumber(double value) {
        return String.format("%.3f", value);
    }

    private String formatNumber(String value) {
        return String.format("%.2f", Double.parseDouble(value));
    }

    public static void main(String[] args) {
        HelperService hs = new HelperService();
        System.out.println(hs.formatNumber(500));
        System.out.println(hs.formatNumber(89.9934));
        System.out.println(hs.formatNumber("550"));
    }
}
```

### 输出

```bash
500
89.993
550.00
```

## 要点

- 方法重载要求同一类中的方法具有不同的参数。
- 重载通过改变参数的数量或类型来实现。
- 只改变返回类型不构成重载；必须存在参数上的差异。
