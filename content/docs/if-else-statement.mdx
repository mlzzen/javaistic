在编程中，我们使用 `if..else` 语句在多个选项中执行一个代码块。

例如，根据学生获得的百分比来评定等级（A、B、C）。

- 如果百分比高于 **90**，评为 **A** 等
- 如果百分比高于 **75**，评为 **B** 等
- 如果百分比高于 **65**，评为 **C** 等

## 1. Java if（if-then）语句

**if-then** 语句的语法是：

```java
if (condition) {
  // statements
}
```

这里，`condition` 是一个布尔表达式，例如 `age >= 18`。

- 如果 `condition` 的求值结果为 `true`，则执行语句
- 如果 `condition` 的求值结果为 `false`，则跳过语句

### 示例 1：Java if 语句

```java
class IfStatement {
  public static void main(String[] args) {

    int number = 10;

    // 检查 number 是否小于 0
    if (number < 0) {
      System.out.println("The number is negative.");
    }

    System.out.println("Statement outside if block");
  }
}
```

#### 输出

```plaintext
Statement outside if block
```

在这个程序中，`number < 0` 为 `false`。因此，圆括号内的代码被**跳过**。

## 2. Java if...else（if-then-else）语句

如果测试表达式的求值结果为 `true`，`if` 语句会执行某一段代码。但是，如果测试表达式的求值结果为 `false`，它什么也不做。

在这种情况下，我们可以使用可选的 `else` 块。如果测试表达式的求值结果为 `false`，就会执行 `else` 块主体内的语句。这在 Java 中被称为 **if-...else** 语句。

**if...else** 语句的语法是：

```java
if (condition) {
  // codes in if block
}
else {
  // codes in else block
}
```

这里，如果条件为真，程序将执行一个任务（if 块内的代码）；如果条件为假，则执行另一个任务（else 块内的代码）。

### 示例 3：Java if...else 语句

```java
class Main {
  public static void main(String[] args) {
    int number = 10;

    // 检查 number 是否大于 0
    if (number > 0) {
      System.out.println("The number is positive.");
    }

    // 执行这个代码块
    // 如果 number 不大于 0
    else {
      System.out.println("The number is not positive.");
    }

    System.out.println("Statement outside if...else block");
  }
}
```

#### 输出

```plaintext
The number is positive.
Statement outside if...else block
```

在上面的示例中，我们有一个名为 `number` 的变量。这里，测试表达式 `number > 0` 检查 `number` 是否大于 0。

由于 `number` 的值是 `10`，测试表达式的求值结果为 `true`。因此，执行 `if` 主体内的代码。

现在，把 `number` 的值改为一个负整数。比如 `-5`。

```java
int number = -5;
```

如果用 `number` 的新值运行程序，输出将是：

```plaintext
The number is not positive.
Statement outside if...else block
```

这里，number 的值是 `-5`。所以测试表达式的求值结果为 `false`。因此，执行 `else` 主体内的代码。

## 3. Java if...else...if 语句

在 Java 中，我们有 if...else...if 阶梯，它可以用来在多个代码块中执行一个代码块。

```java
if (condition1) {
  // codes
}
else if(condition2) {
  // codes
}
else if (condition3) {
  // codes
}
.
.
else {
  // codes
}
```

这里，`if` 语句从上到下依次执行。当测试条件为 `true` 时，执行该 `if` 块主体内的代码。然后，程序控制会跳出 **if...else...if** 阶梯。

如果所有测试表达式的求值结果都为 `false`，则执行 `else` 主体内的代码。

## if...else...if 阶梯如何工作？

如果第一个测试条件为真，则执行第一个 if 块内的代码；如果第二个条件为真，则执行第二个 if 块内的代码；如果所有条件都为假，则执行 else 块
if...else...if 阶梯的工作原理

### 示例 4：Java if...else...if 语句

```java
class Main {
  public static void main(String[] args) {

    int number = 0;

    // 检查 number 是否大于 0
    if (number > 0) {
      System.out.println("The number is positive.");
    }

    // 检查 number 是否小于 0
    else if (number < 0) {
      System.out.println("The number is negative.");
    }

    // 如果两个条件都为假
    else {
      System.out.println("The number is 0.");
    }
  }
}
```

#### 输出

```plaintext
The number is 0.
```

在上面的示例中，我们检查 `number` 是**正数**、**负数**还是**零**。这里，我们有两个条件表达式：

- `number > 0` - 检查 `number` 是否大于 `0`。
- `number < 0` - 检查 `number` 是否小于 `0`。

这里，`number` 的值是 `0`。所以两个条件的求值结果都为 `false`。因此，执行 `else` 主体内的语句。

<Callout>

**注意：** Java 提供了一个特殊的运算符，称为**三元运算符**，它是 **if...else...if** 语句的一种简写形式。要了解三元运算符，请访问 [Java 三元运算符](/docs/operators#java-ternary-operator)。

</Callout>

## 4. Java 嵌套 if..else 语句

在 Java 中，也可以在一个 `if...else` 语句内使用 `if..else` 语句。这称为嵌套 `if...else` 语句。

下面是一个使用嵌套 `if...else` 语句找出 **3** 个数中最大值的程序。

### 示例 5：嵌套 if...else 语句

```java
class Main {
  public static void main(String[] args) {

    // 声明 double 类型的变量
    Double n1 = -1.0, n2 = 4.5, n3 = -5.3, largest;

    // 检查 n1 是否大于或等于 n2
    if (n1 >= n2) {

      // if 块内的 if...else 语句
      // 检查 n1 是否大于或等于 n3
      if (n1 >= n3) {
        largest = n1;
      }

      else {
        largest = n3;
      }
    } else {

      // else 块内的 if..else 语句
      // 检查 n2 是否大于或等于 n3
      if (n2 >= n3) {
        largest = n2;
      }

      else {
        largest = n3;
      }
    }

    System.out.println("Largest Number: " + largest);
  }
}
```

#### 输出：

```plaintext
Largest Number: 4.5
```

在上面的程序中，我们为了方便直接自己给变量赋了值。

然而，在实际应用中，这些值可能来自用户输入的数据、日志文件、表单提交等。
