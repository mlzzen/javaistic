## 什么是 JVM？

**JVM（Java 虚拟机）** 是一台抽象机器，它让你的计算机能够运行 Java 程序。

当你运行 Java 程序时，Java 编译器会先把你的 Java 代码编译成字节码。然后，JVM 把字节码转换成原生机器码（计算机 CPU 直接执行的一组指令）。

Java 是一门**与平台无关的语言**。这是因为你编写 Java 代码时，它最终是为 JVM 而不是你的物理机器（计算机）编写的。由于 JVM 执行的是与平台无关的 Java 字节码，所以 Java 是平台无关的。

## 什么是 JRE？

**JRE（Java 运行环境）** 是一个软件包，它提供 Java 类库、**Java 虚拟机（JVM）** 以及运行 Java 应用程序所需的其他组件。

JRE 是 JVM 的超集。

## 什么是 JDK？

**JDK（Java 开发工具包）** 是开发 Java 应用程序所需的软件开发工具包。当你下载 JDK 时，JRE 也会随之一起下载。

除了 JRE，JDK 还包含许多开发工具（编译器、JavaDoc、Java 调试器等）。
