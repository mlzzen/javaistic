运算符是对变量和值执行运算的符号。例如，`+` 是用于加法的运算符，而 `*` 也是用于乘法的运算符。

Java 中的运算符可以分为 5 种类型：

1. 算术运算符
2. 赋值运算符
3. 关系运算符
4. 逻辑运算符
5. 一元运算符
6. 位运算符

## 1. Java 算术运算符

算术运算符用于对变量和数据进行算术运算。例如，

```java
a + b;
```

这里的 `+` 运算符用于把两个变量 `a` 和 `b` 相加。类似地，Java 中还有许多其他算术运算符。

| 运算符 |                   运算                   |
| :------: | :------------------------------------------: |
|  **+**   |                   加法                   |
|  **-**   |                 减法                 |
|  **\***  |                乘法                |
|  **/**   |                   除法                   |
|  **%**   | 取模运算（除法后的余数） |

#### 示例 1：算术运算符

```java
class Main {
  public static void main(String[] args) {

    // 声明变量
    int a = 12, b = 5;

    // 加法运算符
    System.out.println("a + b = " + (a + b));

    // 减法运算符
    System.out.println("a - b = " + (a - b));

    // 乘法运算符
    System.out.println("a * b = " + (a * b));

    // 除法运算符
    System.out.println("a / b = " + (a / b));

    // 取模运算符
    System.out.println("a % b = " + (a % b));
  }
}
```

#### 输出

```plaintext
a + b = 17
a - b = 7
a * b = 60
a / b = 2
a % b = 2
```

在上面的示例中，我们使用了 `+`、`-` 和 `*` 运算符来计算加法、减法和乘法运算。

### / 除法运算符

注意我们程序中的运算 `a / b`。`/` 运算符就是除法运算符。

如果我们对两个整数使用除法运算符，那么得到的商也会是一个整数。而如果其中一个操作数是浮点数，我们得到的结果也会是浮点数。

```java
In Java,

(9 / 2) is 4
(9.0 / 2) is 4.5
(9 / 2.0) is 4.5
(9.0 / 2.0) is 4.5
```

### % 取模运算符

取模运算符 `%` 计算余数。当 `a = 7` 除以 `b = 4` 时，余数是 **3**。

## 2. Java 赋值运算符

赋值运算符在 Java 中用于给变量赋值。例如，

```java
int age;
age = 5;
```

这里，= 是赋值运算符。它把右侧的值赋给左侧的变量。也就是说，5 被赋给了变量 age。

让我们再看看 Java 中可用的其他一些赋值运算符。

| 运算符 | 示例  | 等价于 |
| :------: | :------: | :-----------: |
|    =     |  a = b;  |    a = b;     |
|    +=    | a += b;  |  a = a + b;   |
|    -=    | a -= b;  |  a = a - b;   |
|   \*=    | a \*= b; |  a = a \* b;  |
|    /=    | a /= b;  |  a = a / b;   |
|    %=    | a %= b;  |  a = a % b;   |

#### 示例 2：赋值运算符

```java
class Main {
  public static void main(String[] args) {

    // 创建变量
    int a = 4;
    int var;

    // 使用 = 赋值
    var = a;
    System.out.println("var using =: " + var);

    // 使用 =+ 赋值
    var += a;
    System.out.println("var using +=: " + var);

    // 使用 =* 赋值
    var *= a;
    System.out.println("var using *=: " + var);
  }
}
```

输出

```plaintext
var using =: 4
var using +=: 8
var using *=: 32
```

## 3. Java 关系运算符

关系运算符用于检查两个操作数之间的关系。例如，

```java
// 检查 a 是否小于 b
a < b;
```

这里，`>` 运算符是关系运算符。它检查 `a` 是否小于 `b`。

它返回 true 或 false。

| 运算符 |       描述        |        示例         |
| :------: | :----------------------: | :--------------------: |
|    ==    |       等于        |  3 == 5 返回 false  |
|    !=    |       不等于       |  3 != 5 返回 true   |
|   `>`    |       大于       | 3 `>` 5 返回 false  |
|   `<`    |        小于         |  3 `<` 5 返回 true  |
|   `>=`   | 大于或等于 | 3 `>=` 5 返回 false |
|   `<=`   |  小于或等于  | 3 `<=` 5 返回 true  |

#### 示例 3：关系运算符

```java
class Main {
  public static void main(String[] args) {

    // 创建变量
    int a = 7, b = 11;

    // a 和 b 的值
    System.out.println("a is " + a + " and b is " + b);

    // == 运算符
    System.out.println(a == b);  // false

    // != 运算符
    System.out.println(a != b);  // true

    // > 运算符
    System.out.println(a > b);  // false

    // < 运算符
    System.out.println(a < b);  // true

    // >= 运算符
    System.out.println(a >= b);  // false

    // <= 运算符
    System.out.println(a <= b);  // true
  }
}
```

## 4. Java 逻辑运算符

逻辑运算符用于检查表达式为 true 还是 false。它们用于决策。

  <thead>
    <tr>
      <th>运算符</th>
      <th>示例</th>
      <th>含义</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>&&（逻辑与）</td>
      <td>expression1 && expression2 </td>
      <td>仅当 expression1 和 expression2 都为 true 时才为 true </td>
    </tr>
    <tr>
      <td>||（逻辑或）</td>
      <td>expression1 || expression2</td>
      <td>只要 expression1 或 expression2 中有一个为 true 就为 true</td>
    </tr>
    <tr>
      <td>!（逻辑非）</td>
      <td>!expression</td>
      <td>若 expression 为 false 则为 true，反之亦然</td>
    </tr>
  </tbody>
</table>

#### 示例 4：逻辑运算符

```java
class Main {
  public static void main(String[] args) {

    // && 运算符
    System.out.println((5 > 3) && (8 > 5));  // true
    System.out.println((5 > 3) && (8 < 5));  // false

    // || 运算符
    System.out.println((5 < 3) || (8 > 5));  // true
    System.out.println((5 > 3) || (8 < 5));  // true
    System.out.println((5 < 3) || (8 < 5));  // false

    // ! 运算符
    System.out.println(!(5 == 3));  // true
    System.out.println(!(5 > 3));  // false
  }
}
```

#### 程序运行原理

- (5 > 3) && (8 > 5) 返回 true，因为 (5 > 3) 和 (8 > 5) 都为 true。
- (5 > 3) && (8 < 5) 返回 false，因为表达式 (8 < 5) 为 false。
- (5 < 3) || (8 > 5) 返回 true，因为表达式 (8 > 5) 为 true。
- (5 > 3) && (8 > 5) 返回 true，因为表达式 (5 > 3) 为 true。
- (5 > 3) && (8 > 5) 返回 false，因为 (5 < 3) 和 (8 < 5) 都为 false。
- !(5 == 3) 返回 true，因为 5 == 3 为 false。
- !(5 > 3) 返回 false，因为 5 > 3 为 true。

## 5. Java 一元运算符

一元运算符只与一个操作数一起使用。例如，++ 是一个一元运算符，它会把变量的值增加 1。也就是说，++5 将返回 6。

不同类型的一元运算符包括：

| 运算符 |                                   含义                                    |
| :------: | :--------------------------------------------------------------------------: |
|    +     | 一元加：不必使用，因为数字不加它也是正数 |
|    -     |                一元减：反转表达式的符号                |
|    ++    |                  自增运算符：把值增加 1                   |
|    --    |                  自减运算符：把值减少 1                   |
|    !     |         逻辑补运算符：反转布尔值          |

### 自增和自减运算符

Java 还提供了自增和自减运算符：分别是 **++** 和 **- -**。**++** 会把操作数的值增加 **1**，而 **- -** 会把它减少 **1**。例如，

```java
int num = 5;

// 把 num 增加 1
++num;
```

这里，`num` 的值从初始的 **5** 增加到了 **6**。

#### 示例 5：自增和自减运算符

```java
class Main {
  public static void main(String[] args) {

    // 声明变量
    int a = 12, b = 12;
    int result1, result2;

    // 原始值
    System.out.println("Value of a: " + a);

    // 自增运算符
    result1 = ++a;
    System.out.println("After increment: " + result1);

    System.out.println("Value of b: " + b);

    // 自减运算符
    result2 = --b;
    System.out.println("After decrement: " + result2);
  }
}
```

#### 输出

```plaintext
Value of a: 12
After increment: 13
Value of b: 12
After decrement: 11
```

在上面的程序中，我们把 ++ 和 - - 运算符用作 **前缀（++a, - -b）**。我们也可以把它们用作 **后缀（a++, b++）**。

这些运算符用作前缀时与用作后缀时有一点细微的差别。

## 6. Java 位运算符

Java 中的位运算符用于对各个位执行运算。例如，

```plaintext
Bitwise complement Operation of 35

35 = 00100011 (In Binary)

~ 00100011
  ________
   11011100  = 220 (In decimal)
```

这里，`~` 是一个位运算符。它会反转每一位的值（**0** 变 **1**，**1** 变 **0**）。

Java 中存在的各种位运算符有：

| 运算符 |     描述      |
| :------: | :------------------: |
|    ~     |  按位取反  |
|   `<<`   |      左移      |
|    >>    |     右移     |
|   >>>    | 无符号右移 |
|    &     |     按位与      |
|    ^     | 按位异或 |

这些运算符在 Java 中一般不太常用。要了解更多内容，请访问 [Java 位运算与位移运算符](/bitwise-and-bit-shift-operators-in-java)。

## 7. 其他运算符

除了这些运算符之外，Java 中还有其他一些运算符。

### Java instanceof 运算符

`instanceof` 运算符检查一个对象是否为某个特定类的实例。例如，

```java
class Main {
  public static void main(String[] args) {

    String str = "";
    boolean result;

    // 检查 str 是否为
    // String 类的实例
    result = str instanceof String;
    System.out.println("Is str an object of String? " + result);
  }
}
```

输出

```plaintext
Is str an object of String? true
```

这里，str 是 String 类的一个实例。因此，instanceof 运算符返回 true。要了解更多内容，请访问 Java instanceof。

### Java 三元运算符

三元运算符（条件运算符）是 if-then-else 语句的简写形式。例如，

```java
variable = Expression ? expression1 : expression2
```

它的工作方式如下。

- 如果 `Expression` 为 `true`，则把 `expression1` 赋给 `variable`。
- 如果 `Expression` 为 `false`，则把 `expression2` 赋给 `variable`。
  让我们看一个三元运算符的例子。

```java
class Java {
  public static void main(String[] args) {

    int februaryDays = 29;
    String result;

    // 三元运算符
    result = (februaryDays == 28) ? "Not a leap year" : "Leap year";
    System.out.println(result);
  }
}
```

输出

```plaintext
Leap year
```

在上面的示例中，我们使用三元运算符来检查某一年是否为闰年。要了解更多内容，请访问 [Java 三元运算符](/docs/operators#java-ternary-operator)。
