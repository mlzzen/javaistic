在 Java 中，**for-each 循环**用于遍历[数组](/docs/arrays)和集合（例如 [ArrayList](/docs/arraylist)）中的元素。它也被称为增强 for 循环。

## `for-each` 循环的语法

Java **for-each** 循环的语法是：

```java
for(dataType item : array) {
    ...
}
```

这里的含义是：

- **array** —— 数组或集合
- **item** —— 数组/集合中的每个元素都会赋值给这个变量
- **dataType** —— 数组/集合的数据类型

### 示例 1：打印数组元素

#### 输入

```java
// 打印数组元素

class Main {
  public static void main(String[] args) {

    // 创建一个数组
    int[] numbers = {3, 9, 5, -5};

    // for-each 循环
    for (int number: numbers) {
      System.out.println(number);
    }
  }
}
```

#### 输出

```plaintext
3
9
5
-5
```

这里，我们使用 **for-each 循环**逐个打印了 numbers 数组的每个元素。

- 在第 1 次迭代中，元素为 3。
- 在第 2 次迭代中，元素为 9。
- 在第 3 次迭代中，元素为 5。
- 在第 4 次迭代中，元素为 -5。

### 示例 2：数组元素求和

#### 输入

```java
// 计算数组所有元素的和

class Main {
 public static void main(String[] args) {

   // 一个数字数组
   int[] numbers = {3, 4, 5, -5, 0, 12};
   int sum = 0;

   // 遍历数组的每个元素
   for (int number: numbers) {
     sum += number;
   }

   System.out.println("Sum = " + sum);
 }
}
```

#### 输出：

```plaintext
Sum = 19
```

在上面的程序中，for-each 循环的执行过程如下：

| 迭代 | 变量                                |
| ---- | ----------------------------------- |
| 1    | `number` = 3 `sum` = 0 + 3 = 3      |
| 2    | `number` = 4 `sum` = 3 + 4 = 7      |
| 3    | `number` = 5 `sum` = 7 + 5 = 12     |
| 4    | `number` = -5 `sum` = 12 + (-5) = 7 |
| 5    | `number` = 0 `sum` = 7 + 0 = 7      |
| 6    | `number` = 12 `sum` = 7 + 12 = 19   |

可以看到，在循环的每次迭代中，我们都把 `numbers` 数组的一个元素加到了 `sum` 变量上。

## for 循环与 for-each 循环的对比

下面来看 for-each 循环与普通的 [Java for 循环](/docs/for-loop)有何不同。

### 1. 使用 for 循环

#### 输入

```java
class Main {
 public static void main(String[] args) {

   char[] vowels = {'a', 'e', 'i', 'o', 'u'};

   // 使用 for 循环遍历数组
   for (int i = 0; i < vowels.length; ++ i) {
     System.out.println(vowels[i]);
   }
 }
}
```

#### 输出：

```plaintext
a
e
i
o
u
```

### 2. 使用 for-each 循环

#### 输入

```java
class Main {
 public static void main(String[] args) {

   char[] vowels = {'a', 'e', 'i', 'o', 'u'};

   // 使用 for-each 循环遍历数组
   for (char item: vowels) {
     System.out.println(item);
   }
 }
}
```

#### 输出：

```plaintext
a
e
i
o
u
```

这里，两个程序的输出完全相同。不过，**for-each** 循环写起来更简单，也更容易理解。

所以在处理数组和集合时，**for-each** 循环比 **for** 循环更受推荐。
